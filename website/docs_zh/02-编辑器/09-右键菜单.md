# 右键菜单

在编辑区**右键点击**会打开上下文菜单，集中提供常用的格式化与插入命令。它和工具栏、快捷键互补，是鼠标流用户的高效入口。

> [!NOTE]右键菜单中的命令大多也有对应快捷键，括号内为默认绑定。完整列表见 [[07-设置/04-快捷键速查]]。

## 菜单结构

菜单分为三行图标按钮与两个子菜单：

| 分区 | 内容 |
| --- | --- |
| 第一行 · 剪贴板 | 剪切、复制、粘贴、删除 |
| 第二行 · 行内格式 | 加粗、斜体、删除线、行内代码、链接 |
| 第三行 · 块级格式 | 引用、无序列表、有序列表、任务列表、高亮 |
| 子菜单 · 标题 | 一 ~ 六级标题、段落 |
| 子菜单 · 插入 | 图像、水平分割线、表格、代码块、公式块、WikiLink |

## 剪贴板

- **剪切** / **复制** / **粘贴** —— 标准剪贴板操作
- **删除** —— 删除当前选区或光标所在块

## 格式化

| 命令 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 加粗 | `Ctrl+B` | 包裹选中文本为粗体 |
| 斜体 | `Ctrl+I` | 包裹选中文本为斜体 |
| 删除线 | `Ctrl+D` | 包裹选中文本为删除线 |
| 行内代码 | `Ctrl+E` | 包裹选中文本为 `行内代码` |
| 链接 | `Ctrl+K` | 打开「插入链接」弹窗，填写链接文本与 URL |
| 高亮 | `Ctrl+=` | 包裹选中文本为 `==高亮==` |

## 标题

选中文本（或把光标放在段落中）后，可快速设置为 1–6 级标题，或转换回普通段落。

> 快捷键：`Ctrl+1` \~ `Ctrl+6`，段落为 `Ctrl+0`。

## 列表与引用

| 命令 | 默认快捷键 |
| --- | --- |
| 引用 | `Ctrl+;` |
| 无序列表 | `Ctrl+L` |
| 有序列表 | 无默认绑定 |
| 任务列表 | `Ctrl+J` |

> [!TIP]「有序列表」默认没有绑定快捷键（`Ctrl+O` 属于「快速打开文件」）。如需快捷键，请在 [[07-设置/03-快捷键设置]] 中自行分配。

## 插入子菜单

| 命令 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 图像 | 无 | 打开文件选择器，插入图片（按 [[07-设置/06-图片设置]] 的规则落盘） |
| 水平分割线 | `Ctrl+Shift+H` | 插入 `---` |
| 表格 | `Ctrl+T` | 插入表格 |
| 代码块 | `Ctrl+U` | 插入代码块 |
| 公式块 | 无 | 打开公式编辑弹窗，确认后插入块级公式 |
| WikiLink | 无 | 插入 `[[` 并立即唤出自动补全列表 |

> [!TIP]想批量套用格式时，先选中一段文字再右键，菜单命令会直接作用于选区；若未选中，则作用于当前光标所在块。
