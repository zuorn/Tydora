# 常见问题（FAQ）

本页汇总使用 Tydora 时的高频问题与排错思路。若未覆盖你的问题，欢迎到 GitHub Issues 反馈（见 [[01-开始使用/02-关于]]）。

## 入门与基础

### 第一次打开该选哪个仓库？

仓库就是「一个本地文件夹」。建议为不同用途建不同文件夹（如 `工作笔记`、`个人知识库`），再通过仓库切换器分别添加。详见 [[04-文件管理/01-仓库]]。

### 文件会被移动或修改吗？

不会。Tydora 只读取与写入你指定的文件，**不会**移动、复制或改动仓库结构。移除仓库也只是解除引用。详见 [[04-文件管理/01-仓库]]。

### 删除的笔记能恢复吗？

**不能。** 删除操作不可撤销，不走系统回收站，且会递归删除文件夹内全部内容。重要资料请先备份或纳入 Git 等版本管理。

### 界面想换成英文？

打开设置（`Ctrl+,`）→「通用」标签 →「语言」，可在「简体中文」与「English」之间切换，立即生效。

## 编辑与快捷键

### 为什么 `Ctrl+O` 是打开文件，而不是有序列表？

因为默认配置中「有序列表」**没有绑定任何快捷键**，`Ctrl+O` 只属于「快速打开文件」。若你希望用快捷键插入有序列表，请在 [[07-设置/03-快捷键设置]] 中为它自行分配。详见 [[07-设置/04-快捷键速查]]。

### 怎么在即时渲染和源码之间切换？

按 `Ctrl+/` 一键切换；也可在命令面板中执行「切换到即时渲染模式 / 切换到源码模式」。详见 [[02-编辑器/01-编辑模式]]。

### 标题快捷键是 `Ctrl+1` 还是 `Ctrl+Alt+1`？

是 `Ctrl+1` \~ `Ctrl+6`，`Ctrl+0` 恢复为正文段落。所有快捷键都能在 [[07-设置/03-快捷键设置]] 中查看与修改。

### 表格怎么快速增删行列？

在即时渲染下，把光标放入表格会出现浮动工具栏，可直接增删行列、对齐、合并 / 拆分单元格；快捷键见 [[07-设置/04-快捷键速查]] 的「表格」分组。详见 [[02-编辑器/08-表格操作]]。

### `Ctrl+F` 找不到东西？

`Ctrl+F` 是**当前文档内**的查找，`Ctrl+H` 是替换。若要在整个仓库里搜文件与正文，请用侧栏「搜索」页签或 `Ctrl+O` 快速打开。详见 [[02-编辑器/12-查找与替换]]。

### Vim 模式怎么开？开了会不会影响原有快捷键？

设置 →「Vim 模式」→ 开启「启用 Vim 模式」（默认关闭）。开启后源码模式与即时渲染模式都支持 normal / insert / visual 三态。部分 App 快捷键（如 `Ctrl+D`、`Ctrl+U`、`Ctrl+F`）在 Vim 下有冲突，可在该设置页逐项决定是否让渡给 Vim。详见 [[02-编辑器/11-Vim模式]]。

## 知识管理

### `[[双链]]` 点击没反应 / 显示找不到？

- 确认链接的笔记名拼写正确，且存在于当前仓库
- 链接解析依赖 [[03-知识管理/05-链接索引]]，首次打开大仓库时索引可能仍在构建，稍候即可
- 文件名改过名时，Tydora 会尝试修复旧链接；若仍失效，检查是否跨仓库（链接默认只在当前仓库内解析）

### 反向链接在哪里看？

侧栏没有独立的「反向链接」页签。反链 / 出链信息以**徽标**形式显示在文件树的文件项上；按 `Ctrl+G` 打开 [[03-知识管理/04-知识图谱]] 可以从网状视角观察引用关系。详见 [[03-知识管理/03-反向链接]]。

### 知识图谱是空的？

图谱只展示存在 `[[03-知识管理/01-Wiki链接]]` 关系的笔记。若仓库里还没有任何双链，图谱自然为空。先建立几条链接再看。详见 [[03-知识管理/04-知识图谱]]。

### 标签是怎么用的？和 Frontmatter 里的 `tags` 是一回事吗？

两者都会被纳入标签索引。正文里直接写 `#标签名`，或在 Frontmatter 写 `tags: [标签名]` 都可以。侧栏「标签」页签提供列表与标签图谱两种视图，点击标签会在搜索框中填入 `#标签名` 做全局筛选。详见 [[03-知识管理/06-标签]]。

### 书签怎么添加？

在文件树中右键文件或文件夹 →「收藏」，即可加入侧栏「书签」页签，并支持分组、重命名与拖拽排序。详见 [[03-知识管理/07-书签]]。

## 渲染与显示

### 数学公式不显示？

- 检查语法：行内用 `$...$`，块级用 `$$...$$`
- 复杂公式若报错，可用右键菜单的「插入 → 公式块」打开公式编辑弹窗，边写边看预览
- Tydora 使用 **KaTeX** 渲染，没有 MathJax 引擎可切换

详见 [[02-编辑器/04-数学公式]]。

### Mermaid 图表没渲染？

- 确认代码块语言标注为 `mermaid`
- 检查语法括号、箭头是否配对，可对照 [Mermaid 官方文档](https://mermaid.js.org/)
- 详见 [[02-编辑器/05-Mermaid图表]]

### 界面显示异常（样式错乱、图表不更新）？

先尝试以下操作，通常可恢复：

1. 在编辑器里切换一次编辑模式（`Ctrl+/`），强制重绘
2. 完全退出并重启 Tydora
3. 若只有某个仓库异常，可在侧栏「文件」页签右上角执行「折叠全部 / 展开全部」重新加载文件树

> [!NOTE]
> 应用**没有**「清除缓存」按钮；如问题持续，请到 GitHub Issues 反馈并附上截图。

### 主题/代码高亮想换？

- 应用主题：[[06-主题与外观/01-内置主题]]（10 款），也可自建 [[06-主题与外观/02-自定义主题]]
- 代码配色：[[06-主题与外观/03-代码高亮主题]]（11 款，可跟随应用主题自动切换）

### 主题能像 Typora 那样导入第三方 CSS 吗？

Tydora 不支持导入 Typora 主题。自定义主题需要在设置中**新建 / 复制内置主题**后逐项调整颜色，或导入 `.tydora-theme.json` 主题包（由 Tydora 自身导出）。详见 [[06-主题与外观/02-自定义主题]]。

## 终端与分屏

### 怎么打开终端？

按 ``Ctrl+` `` 新建终端窗格。终端使用真实 shell（Windows 下为 PowerShell 等系统 shell），支持查找、右键菜单与配色方案切换。详见 [[08-高级功能/05-终端]]。

### 怎么左右分屏？

`Ctrl+\` 左右分屏，`Ctrl+-` 上下分屏。分屏后可在窗格之间拖动标签页，或把终端放进新窗格。详见 [[05-导航与搜索/04-分屏与多窗格]]。

## 发布与导出

### 提示「未找到 markdown-publish CLI」？

发布功能依赖的 CLI 没有随安装包分发，需要手动装一次：先安装 [Node.js](https://nodejs.org)，再执行 `npm install -g @abstractwebunit/markdown-publish`，然后重启 Tydora。详见 [[08-高级功能/01-发布网站]]。

### 发布到 GitHub Pages 后资源 404？

多半是 Base Path 没设对。在发布配置中把「Base Path」填为 `/<仓库名>/`，「站点 URL」填 `https://<用户名>.github.io/<仓库名>/`。详见 [[08-高级功能/01-发布网站]]。

### 只想发布部分笔记怎么办？

用「仅公开笔记」模式，并在要公开的笔记 Frontmatter 写 `publish: public`。详见 [[08-高级功能/01-发布网站]] 与 [[02-编辑器/07-Frontmatter]]。

### 能导出成 Word / PDF 吗？

可以。命令面板（`Ctrl+P`）中搜索「导出」，支持 PDF、HTML、Word、长图、图文卡片；也可以「复制为 Markdown」或「复制公众号」直接粘贴到目标平台。详见 [[08-高级功能/04-导出与复制]]。

### 自动更新失败 / 一直提示签名错误？

通常是签名密钥或 GitHub Secret 配置问题。请核对 [[09-blog/自动更新配置]] 中的密钥生成、Secret 填写与 `app/tydora-desktop/tauri.conf.json` 公钥。

## 隐私与统计

### Tydora 会上传我的笔记吗？

不会。笔记内容、文件名、仓库结构、剪贴板内容都只留在本地。详见 [[01-开始使用/隐私策略]]。

### 设置里的「陪你走得更远 🌿」是什么？

那是匿名使用统计开关。首次启动会弹窗征求同意，同意后只上报行为事件名（如「打开设置」「导出 PDF」）与少量属性，**绝不包含文件路径、文件名或文档内容**，事件名走白名单校验。你可以随时在设置中关闭，关闭后不再发送任何数据。
