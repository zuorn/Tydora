# 发布网站

Tydora 可以把你的笔记仓库（Vault）**一键发布为静态网站**，无需搭建服务器，就能把知识库、文档或数字花园分享给任何人。

> [!NOTE]
> 发布功能在设置「发布」标签（或发布面板）中操作，底层由 `@abstractwebunit/markdown-publish` 构建为静态站点。

## 前置条件

发布功能依赖 `@abstractwebunit/markdown-publish` CLI，安装包**不自带**该 CLI，需要你先手动安装一次：

1. 安装 [Node.js](https://nodejs.org)（建议 18 及以上）。
2. 在终端执行：

   ```bash
   npm install -g @abstractwebunit/markdown-publish
   ```

3. 重启 Tydora。

> [!IMPORTANT]
> 未安装时点击「发布」会提示「未找到 markdown-publish CLI」。CLI 自身依赖 Angular 等较大依赖，随安装包分发会让安装包从约 7 MB 膨胀到 20 MB 以上，因此改为按需安装。

## 发布流程

1. **配置发布设置**：填写站点名称、描述、语言等基本信息。
2. **选择发布模式**：完整发布，或仅公开笔记。
3. **开始发布**：一键构建静态网站。
4. **预览或部署**：本地预览，或把产物上传到任意静态托管服务。

## 发布模式

### 完整发布

发布 Vault 中的**所有** Markdown 文件。适合个人知识库、项目文档等「整库对外」的场景。

### 仅公开笔记

仅发布 Frontmatter 中带 `publish: public` 的文件。适合「同一仓库、选择性分享」的场景——把私密笔记留在本地，只把精选内容放出。

> 如何标记公开笔记：在文件开头写 `publish: public`，详见 [[02-编辑器/07-Frontmatter]]。

## 发布配置

| 配置项 | 说明 |
| --- | --- |
| 站点名称 | 网站标题（`<title>`） |
| 站点描述 | 网站描述，用于 SEO |
| 语言 | 网站语言（中文 / 英文 / 日文 / 韩文） |
| 站点 URL | 最终部署的网站地址（用于绝对链接与 sitemap） |
| 页脚 | 自定义页脚内容 |
| 仓库目录 | Vault 中要发布的目录（可指定子目录） |
| 构建模式 | 完整发布 / 仅公开笔记 |
| Base Path | 部署到子路径时填写，例如 GitHub Pages 的 `/<repo>/` |
| 输出目录 | 构建产物的输出位置 |

> [!TIP]
> 部署到 GitHub Pages 时，记得在「站点 URL」填 `https://<用户名>.github.io/<仓库>/`，并在「Base Path」填 `/<仓库>/`，否则资源路径会 404。

## 预览站点

构建完成后，你可以：

- **本地预览**：启动内置 HTTP 服务器，在浏览器中查看效果
- **打开目录**：在文件管理器中打开输出目录，检查产物
- **直接部署**：把输出目录整体上传到静态托管服务

## 技术实现

- 基于 `@abstractwebunit/markdown-publish` CLI 构建
- 生成静态站点（含客户端路由）
- 保留 `[[03-知识管理/01-Wiki链接]]` 在站点内的导航能力
- 发布后对 Callout、Mermaid、数学公式等富元素正常渲染

## 部署建议

构建出的静态站点可托管到任意支持静态文件的服务：

| 平台 | 说明 |
| --- | --- |
| GitHub Pages | 免费，支持自定义域名 |
| Vercel | 一键部署，全球 CDN |
| Netlify | 支持表单与函数 |
| 自有服务器 | 任意 HTTP 服务器（Nginx / Apache 等） |
