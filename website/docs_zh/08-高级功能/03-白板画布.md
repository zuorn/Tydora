# 白板画布

白板画布（Canvas）基于 **React Flow** 构建，提供一个**无限画布**，让你用节点自由组织想法、笔记、图片、媒体与链接——像在纸上铺开，却可无限延展、随手连线。

> [!NOTE]
> 白板文件以 `.canvas` 扩展名保存，采用与 Obsidian 兼容的 **JSON Canvas** 格式。

## 打开白板

- 在文件树中右键 →「新建白板」，创建并打开一个新白板
- 在文件树中点击已有的 `.canvas` 文件
- 白板也可以独立开窗，方便放到副屏

新建白板的存放位置由 [[07-设置/07-白板设置]] 决定（仓库根目录 / 当前文件夹 / 指定附件文件夹）。

## 节点类型

白板兼容 JSON Canvas 规范，支持 **7 种节点**：

| 类型 | 说明 |
| --- | --- |
| **文本卡片（text）** | 自由编辑的文本块，使用 TipTap 即时渲染，支持 Markdown 语法 |
| **笔记卡片（note）** | 引用仓库中的 Markdown 文件，显示笔记内容，与 WikiLink 体系互通 |
| **文件引用（file）** | 引用仓库中的文件（含图片、PDF 等），图片直接显示 |
| **多媒体（media）** | 视频 / 音频等媒体文件，显示播放器或图标 |
| **白板（canvas）** | 嵌套引用另一个白板文件 |
| **链接（link）** | 嵌入外部 URL，点击在浏览器打开 |
| **分组（group）** | 把多个节点归为一组，支持设置分组背景与标签 |

> [!TIP]
> 直接把图片文件**拖进白板**即可创建图片节点。

## 工具栏

白板顶部工具栏提供三个添加按钮（点击或拖动到画布上放置）：

| 工具 | 说明 |
| --- | --- |
| 添加卡片 | 新建文本卡片 |
| 添加笔记 | 新建笔记卡片（从仓库中选择） |
| 添加媒体文件 | 插入图片 / 视频 / 音频 / 白板等媒体 |

## 右键菜单

在画布空白处右键：

| 命令 | 说明 |
| --- | --- |
| 添加卡片 | 新建文本卡片 |
| 添加笔记 | 新建笔记卡片 |
| 添加媒体文件 | 插入媒体 |
| 添加链接 | 输入 URL 创建链接节点 |
| 添加分组 | 创建分组容器 |
| 撤销 / 重做 | 操作历史 |

## 画布操作

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放（缩放上下限可在设置中配置） |
| 拖拽空白处 | 平移画布 |
| 拖拽节点 | 移动节点；开启吸附后会出现对齐参考线 |
| 选中节点 | 出现操作手柄，可调整大小、编辑内容、连线 |
| 小地图 | 可在角落显示小地图导航（设置中开启） |

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+Shift+Z` | 重做（备用） |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴节点 |
| `Ctrl+A` | 全选 |
| `Esc` | 取消选中 |
| 方向键 | 移动选中的节点 |

## 文件格式

白板使用 **JSON Canvas** 格式（`.canvas`），与 Obsidian 白板格式兼容：

- **跨平台兼容**：可在支持该格式的工具间互通
- **可版本控制**：纯文本 JSON，适合纳入 Git
- **人类可读**：可直接查看与手工编辑
- **路径使用相对路径**：引用的文件路径相对于仓库根目录，移动画布文件后依然有效

## 独立窗口

白板可在独立 Tauri 窗口中打开：

- 支持多显示器，把白板放在副屏
- 独立操作不影响主窗口编辑
- 窗口位置与大小自动保存恢复
