# 思维导图与关系图谱设置

本页配置 [[08-高级功能/02-思维导图]] 与 [[03-知识管理/04-知识图谱]] 的显示参数。两者是两个**独立**的设置标签：

- 「思维导图」标签 —— Markmap 思维导图
- 「关系图谱」标签 —— D3 力导向知识图谱

> [!NOTE]
> 按 `Ctrl+,` 打开设置，在左侧列表中选择对应标签。

## 思维导图设置

基于 Markmap 渲染，可调参数：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 最大节点宽度 | 节点文字超过此宽度时自动换行 | 200 |
| 水平间距 | 同级节点之间的水平距离 | 80 |
| 垂直间距 | 父子节点之间的垂直距离 | 5 |
| 连线宽度 | 节点之间连线的粗细 | 1.5 |
| 初始展开层级 | 打开思维导图时默认展开到第几级（可选「全部」） | 2 |
| 动画时长 | 展开 / 折叠节点的动画时间（毫秒） | 300 |
| 颜色冻结层级 | 从第几级开始使用固定颜色（可选「不冻结」） | 不冻结 |

> [!TIP]
> 节点很多、结构很深时，把「初始展开层级」调小可以让导图打开即收敛，再按需展开感兴趣的分支。

## 关系图谱设置

基于 D3 力导向布局 + WebGL 渲染，可调参数：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 在新窗口中打开 | 开启后 `Ctrl+G` 与工具栏按钮在独立窗口中打开图谱 | 关闭 |
| 最大节点大小 | 图谱中节点的最大尺寸 | 15 |
| 标签字号 | 节点标签的文字大小 | 11 |
| 连线距离 | 节点之间的理想距离 | 160 |
| 斥力强度 | 节点之间的排斥力，**负值越大间距越大** | -200 |
| 边线透明度 | 连线的可见程度 | 0.8 |

> [!TIP]
> 仓库链接很多时，把「斥力强度」的绝对值调大能让聚类更清晰；链接稀疏时调小可避免节点飞得太散。节点太密看不清标签时，适当降低「标签字号」或提高「连线距离」。
