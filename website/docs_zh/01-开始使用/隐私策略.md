# Tydora 隐私策略

本隐私策略说明了 Tydora（以下简称「本应用」）在收集、使用和共享用户信息方面的做法。
**你的笔记内容始终归你所有，并存储在你自己的设备上；本应用不会上传你的任何笔记内容、文件名或仓库结构。**

> 本策略最后更新日期：2026 年 9 月 10 日。
> 如本策略有重大变更，我们会通过应用内通知或 GitHub Releases 更新说明的方式告知你。

## 一、我们收集了哪些信息

**Tydora 是一款本地优先（local-first）的桌面应用，不会主动向任何服务器上传你的笔记内容。**
具体而言：

### 1.1 不会收集的信息

- 你的笔记内容、文件名、仓库文件夹结构 —— **全部保存在你本地指定的目录（Vault）中，本应用不会上传到任何远程服务器。**
- 账号、密码、支付信息 —— 本应用**不存在任何账户系统**，也没有任何付费或订阅功能。
- 剪贴板内容 —— 粘贴操作仅在你的设备本地处理。
- 键盘输入历史 —— 所有输入直接写入本地文件，不做任何记录。
- 地理位置、通讯录、相册、摄像头、麦克风 —— 本应用**从不请求这些系统权限**。

### 1.2 匿名使用统计（可选，默认需你同意）

为了解功能使用情况并定位崩溃与报错，本应用内置了**匿名使用统计**（基于开源统计服务 Umami）：

- **首次启动会弹窗征求你的同意**，只有在你同意之后才会发送任何数据。
- 只上报**行为事件名**与少量非敏感属性，例如「应用启动」「打开设置」「切换主题」「导出 PDF」「发布构建」。
- **绝不收集**文件路径、文件名、文档内容、仓库名称、剪贴板内容或任何可识别个人身份的信息。
- 事件名走**白名单校验**，白名单之外的事件不会被发送，避免意外上报敏感字符串。
- 上报数据通过 `https://gateway.umami.is` 发送，不写入 Cookie；不使用 Google Analytics、App Center、友盟等任何其他分析 SDK。
- 你可以在「设置 → 通用 → 行为」中**随时关闭**该开关，关闭后不再发送任何数据；也可在弹窗中直接拒绝。

### 1.3 可能存在的「本地」非个人信息

以下数据**仅写入你本地设备的存储**，不会被发送到任何服务器：

| 数据类型 | 存储位置 | 用途 |
| --- | --- | --- |
| 编辑器偏好（主题、字体、字号、行高等） | `localStorage`（浏览器/WebView 本地存储） | 记忆你的界面与编辑器设置 |
| 窗口状态（位置、大小、是否最大化） | Tauri `window-state` 插件保存的本地 JSON | 下次启动时恢复窗口布局 |
| 最近使用的仓库列表与当前激活仓库 | `localStorage` | 启动时重新打开上次的仓库 |
| 侧栏宽度、页签分配、面板折叠状态 | `localStorage` | 记住你偏好的 UI 布局 |
| 链接索引、标签索引 | `localStorage` | 加速双链解析、标签筛选与图谱渲染 |
| 书签、自定义快捷键、Vim 配置 | `localStorage` | 记忆你的个性化设置 |
| 粘贴图片产生的副本 | 仓库下的 `assets/` 目录（可在设置中改用固定目录） | 支持从剪贴板直接粘贴图片到笔记 |

### 1.4 自动更新

- 启动时，更新器会向 **GitHub Releases** 发起一次 HTTPS 请求，检查是否存在更新。
- 这个请求**只发送应用版本号和当前操作系统**，不包含任何个人数据，GitHub 端可能会记录普通的 Web 访问日志（IP、UA）——这是 GitHub 服务的通用行为，与 Tydora 无关。
- 微软商店版本改为跟随商店更新，检测到 GitHub 有更高版本时由你主动确认才会切换渠道。

### 1.5 微软商店分发版（MSIX）

- 如果你通过**微软商店**安装本应用，Microsoft 会根据其自己的隐私策略收集标准的应用商店遥测（安装、卸载、崩溃报告等）。**这部分数据由 Microsoft 处理，我们不直接访问。**
- 本应用本身不接入 Microsoft Store Analytics SDK，也不主动向 Microsoft 发送任何额外遥测。
- 微软隐私声明详见：[https://privacy.microsoft.com/zh-cn/privacystatement](https://privacy.microsoft.com/zh-cn/privacystatement)

## 二、我们如何使用信息

除上述可选匿名统计外，本应用**不收集任何个人信息**，因此不存在对个人信息的「使用」。应用内所有编辑、索引、图谱与导出操作都在你本地设备上完成。

匿名统计的用途仅限于：了解哪些功能被使用、统计版本分布、发现异常退出的趋势，以决定后续开发优先级。

## 三、共享、披露与第三方传输

- **我们不会与任何第三方共享你的笔记内容**，因为我们根本不持有这些数据。
- 匿名统计事件会发送至 Umami 统计服务，内容仅限白名单事件名与少量非敏感属性，详见 1.2。
- 本应用不含任何广告 SDK，不展示任何广告。

## 四、数据安全

- 所有笔记与仓库文件都存储在你选择的本地文件夹中，安全性由你自己的文件系统和操作系统保证。
- 你可以自行使用云同步（如 OneDrive、iCloud、坚果云等）或版本控制（如 Git）来保护文件，**Tydora 不干预也不拦截这些同步**。
- 由于我们不在服务器端存储你的任何内容，不存在「云端数据库泄露」的风险。

## 五、数据保留与删除

- 本应用产生的所有本地数据（`localStorage`、窗口状态 JSON、`assets/` 图片、笔记文件等）**只要你不删除就会一直保留**。
- 删除方式：
  - 笔记与图片：直接在文件管理器中删除对应文件，或在应用的文件树内右键删除（注意：应用内删除不可撤销）。
  - 应用偏好：卸载应用，或手动删除 `%APPDATA%/com.tydora.editor/`（Windows）下的配置文件。
  - 仓库本身：直接删除你磁盘上的对应文件夹。
- 关闭匿名统计开关后，本应用不再向统计服务发送任何新数据。

## 六、儿童隐私

- 本应用面向普通用户，**没有针对 13 岁以下儿童设计的功能**，且我们不会主动收集任何年龄信息。
- 由于本应用不收集任何个人信息，也不存在儿童个人信息被不当处理的风险。

## 七、适用范围的例外

- **发布到网站功能**：如果你使用 Tydora 内置的「发布网站」功能，生成的静态 HTML 会被保存到你本地指定目录；你可以再自行将这些文件上传到你掌控的任何托管服务。**Tydora 本身不会代你上传任何文件。**
- **内置终端**：终端会话使用你本机的 shell，其行为（包括网络访问）与你在系统终端中直接操作一致，不受本策略约束。
- **外部链接**：应用内如果出现指向外部网站的链接（如文档、开源协议页面、GitHub 链接），点击后由外部网站的隐私策略管辖，与本策略无关。

## 八、你的权利

因为我们不持有你的任何个人信息，所以你不需要向我们行使「访问 / 更正 / 删除 / 导出」等权利——这些数据全部在你自己的磁盘上，你可以直接操作。对于匿名统计，你可以随时在设置中关闭开关。

如果你仍然对本隐私策略有任何疑问或投诉，欢迎通过 GitHub Issues 或邮件方式联系我们。

## 九、策略更新

如果应用功能发生重大变化导致本策略需要调整，我们会：

1. 在本页面（文档站隐私策略页）发布更新版本并标注新的「最后更新日期」；
2. 在应用「设置 → 关于」的更新日志或 GitHub Releases 说明中提及变更概要。
