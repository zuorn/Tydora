# 数学公式

Tydora 使用 **KaTeX** 渲染数学公式，可在行内与块级两种位置书写 LaTeX 公式。

> [!NOTE]
> 公式渲染默认开启。Tydora **只使用 KaTeX**，没有 MathJax 引擎可切换。

## 行内公式

用单个美元符号 `$ ... $` 包裹：

```markdown
质能方程 $E=mc^2$ 是物理学的基础。
```

显示效果：质能方程 $E=mc^2$ 是物理学的基础。

## 块级公式

用两个美元符号 `$$ ... $$` 包裹，公式会独占一行并居中：

```markdown
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

## 公式编辑弹窗

在即时渲染模式下，**点击已渲染的公式**即可打开公式编辑弹窗，边写边看实时预览：

- 输入 LaTeX 后立即在弹窗中预览渲染结果
- 语法错误时会给出提示，不会影响正文
- 也可通过右键菜单「插入」→「公式块」打开空白弹窗，确认后插入块级公式

> 处理复杂公式时，建议用弹窗而非直接手写——预览能第一时间发现括号不配对等问题。

## 常用语法

### 上标与下标

```markdown
$x^2$        → 上标
$H_2O$       → 下标
$x_i^{2n}$   → 上标下标组合
```

### 分数

```markdown
$\frac{a}{b}$
```

### 根号

```markdown
$\sqrt{x}$       → 平方根
$\sqrt[n]{x}$    → n 次方根
```

### 求和、积分与连乘

```markdown
$\sum_{i=1}^{n}$   → 求和
$\int_{a}^{b}$     → 积分
$\prod_{i=1}^{n}$  → 连乘
```

### 希腊字母

```markdown
$\alpha$ $\beta$ $\gamma$ $\delta$
$\pi$ $\sigma$ $\omega$ $\theta$
```

### 矩阵

```markdown
$$
\begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$
```

### 多行对齐

```markdown
$$
\begin{aligned}
a &= b + c \\
  &= d + e
\end{aligned}
$$
```

## 排错建议

- 行内公式必须写成 `$...$`，块级公式写成独占一行的 `$$...$$`
- 下标含多个字符时用花括号包裹，如 `$x_{ij}$` 而不是 `$x_ij$`
- 反斜杠命令（如 `\frac`、`\sum`）不要漏写
- 若某条公式在 KaTeX 下报错，多半用到了 KaTeX 未实现的宏包语法；可改用等价的基础写法

> [!TIP]
> 上标 / 下标的 Markdown 写法（`X^2^`、`H~2~O`）在 Tydora 中**不会**渲染，数学场景请统一使用公式语法。
