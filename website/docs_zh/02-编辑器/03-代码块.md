# 代码块

Tydora 对代码提供完整的语法高亮支持，代码块自带语言选择器、复制与主题切换。

## 创建代码块

### 方法一：Markdown 语法

使用三个反引号包裹代码，并标注语言名称以获得对应高亮：

````markdown
```javascript
function hello() {
  console.log("Hello, Tydora!");
}
```
````

> [!TIP]
> 标注语言（如 `js`、`python`、`rust`）会启用对应的语法高亮；留空或写 `plaintext` 则按纯文本显示。

### 方法二：快捷键

按 `Ctrl+U` 直接插入一个代码块。

### 方法三：右键菜单

1. 在编辑区右键点击。
2. 选择「插入」→「代码块」。

> 插入后可用代码块工具栏的语言选择器切换语言。

## 代码块工具栏

把光标移入代码块，工具栏会浮现，提供：

| 按钮 | 说明 |
| --- | --- |
| 语言选择器 | 在下拉列表中切换高亮语言 |
| 复制 | 复制代码块内容到剪贴板 |
| 删除 | 删除整个代码块 |
| 主题 | 快速切换代码高亮主题 |

工具栏有两种样式，可在 [[07-设置/01-通用设置]] 的「外观」分组中切换：

- **浮动（精简）** —— 只在右上角显示语言选择器，默认样式
- **顶栏（含复制/删除）** —— 顶部完整工具栏，操作按钮更显眼

## 支持的语言

语言选择器内置 **30 种语言**（含 Plain Text）：

Plain Text、JavaScript、TypeScript、Python、Java、C、C++、C#、Go、Rust、Ruby、PHP、Swift、Kotlin、HTML、CSS、SCSS、Less、JSON、YAML、TOML、XML、SQL、Bash、Shell、PowerShell、Markdown、Mermaid、Dockerfile、GraphQL。

此外还额外注册了以下语言的高亮定义，直接手写代码块标注即可生效：

`vim`、`latex`、`nginx`、`cmake`、`scala`、`haskell`、`elixir`、`julia`、`tcl`、`properties`、`gradle`。

## 行内代码

用单个反引号包裹代码片段，适用于正文中的变量名、命令等：

```markdown
使用 `console.log()` 输出日志
```

> 快捷键：`Ctrl+E`。

## 行号

IR 模式下可在 [[07-设置/01-通用设置]] 的「外观」分组中通过「显示行号」开关控制编辑器行号显示，默认开启。

## 复制代码

将鼠标移到代码块上，点击工具栏中的**复制**按钮即可将代码内容复制到剪贴板。

## 代码高亮主题

代码块的配色独立于应用主题，可在设置的「主题」标签中切换，共有 11 款高亮主题：

- 浅色：Atom One Light、GitHub Light、VS Code Light、Solarized Light
- 深色：Atom One Dark、GitHub Dark、VS Code Dark、Nord、Monokai、Dracula、Solarized Dark

> 默认跟随应用外观自动在浅 / 深高亮主题间切换，也可以固定为某一款，或导入 / 自建代码主题。详见 [[06-主题与外观/03-代码高亮主题]]。
