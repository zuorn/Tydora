# 书签

书签用来收藏**经常要用的文件或文件夹**，把它们从深层目录里「拎」到侧栏，一触即达。和 [[03-知识管理/06-标签]] 不同，书签是纯个人视角的组织方式，不写入笔记内容。

> [!NOTE]
> 侧栏的「书签」页签默认分配在**左侧栏**。书签按仓库分别保存，切换仓库时会切换到对应的书签集合。

## 添加书签

1. 在文件树中右键点击文件或文件夹。
2. 选择「收藏」。
3. 在弹出的「添加书签」对话框中填写：

| 字段 | 说明 |
| --- | --- |
| 路径 | 自动填入，不可修改 |
| 标题 | 自定义显示名；**留空则显示原文件名** |
| 分组 | 选择已有分组，或点「+ 新建」创建新分组 |

4. 点击「保存」。

> [!TIP]
> 编辑器顶部「更多」菜单里也有「收藏」，可以在不切回文件树的情况下收藏当前笔记。

## 书签面板

打开侧栏「书签」页签即可看到所有收藏，按**分组**折叠展示：

- 未指定分组的条目归入「未分组」
- 点击书签即可打开对应文件
- 拖动书签可以**跨分组移动**，拖到分组标题上即归入该组
- 未打开仓库时面板显示提示；仓库里没有书签时显示空态引导

## 右键菜单

### 在书签条目上

| 命令 | 说明 |
| --- | --- |
| 在新窗口打开 | 在独立窗口中打开该文件 |
| 修改标题 | 修改书签的显示名（留空则恢复为原文件名） |
| 取消收藏 | 从书签中移除 |
| 复制路径 | 复制文件 / 文件夹的绝对路径 |

### 在分组上

| 命令 | 说明 |
| --- | --- |
| 重命名 | 修改分组名 |
| 删除分组 | 删除分组（组内书签的归属会一并调整） |

## 使用建议

- 把「索引页 / 待办 / 项目主页」这类高频入口收藏起来
- 按用途建分组，例如「写作」「项目」「参考」
- 书签只记录路径，**不会复制文件**；文件被移动或删除后，书签可能失效
