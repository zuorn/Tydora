# 思维导图

Tydora 内置思维导图功能，基于 **Markmap** 将 Markdown 的标题与列表层级自动转换为可交互的思维导图，帮你从「线性文字」切换到「树状结构」来审视内容。

> [!NOTE]
> 快捷键：`Ctrl+M`。思维导图在**独立 Tauri 窗口**中打开，可放到副屏使用。

## 使用方法

1. 按 `Ctrl+M` 打开思维导图。
2. 独立窗口会读取**当前正在编辑的文档**内容并实时生成导图。
3. 用工具栏或鼠标调整视图，点击节点折叠 / 展开分支。

> [!TIP]
> 编辑正文时导图内容会随之更新（带防抖），不需要手动刷新。

## 工具栏

窗口顶部工具栏提供：

| 按钮 | 说明 |
| --- | --- |
| 适配视图 | 自动缩放并居中，把整张导图放进视野 |
| 放大 / 缩小 | 手动调整缩放级别 |
| 展开层级 | 选择默认展开到第几级（全部 / 第 N 级） |
| 导出为图片 | 把当前导图导出为 SVG 图片 |
| 复制图片 | 把导图以 PNG 形式复制到剪贴板，可直接粘贴到聊天或文档 |

## 交互操作

| 操作 | 效果 |
| --- | --- |
| 鼠标右键拖拽 | 平移画布 |
| 滚轮 | 缩放 |
| 方向键 | 在节点间移动焦点 |
| `Enter` / `空格` | 折叠或展开当前节点 |
| 点击节点 | 折叠 / 展开其下级分支 |

## Markdown 格式

思维导图由**标题层级**与**列表层级**生成，无需额外标记：

```markdown
# 根节点
## 一级节点 1
### 二级节点 1.1
### 二级节点 1.2
## 一级节点 2
### 二级节点 2.1
```

- 一级标题 `#` 作为根
- 二级 `##` 作为第一层分支，依此类推
- 标题下的列表会作为子节点展开
- 纯正文段落不进入导图

## 相关设置

在 [[07-设置/05-思维导图设置]] 的「思维导图」标签中可调：

- 最大节点宽度
- 水平间距 / 垂直间距
- 连线宽度
- 初始展开层级
- 动画时长
- 颜色冻结层级

## 使用场景

- **大纲可视化**：写长篇前先列标题，导图一眼看清结构
- **创意发散**：用标题层级做头脑风暴的骨架
- **项目规划**：把目标 → 阶段 → 任务逐层展开
- **知识整理**：把一篇读书笔记的章节变成知识地图

> [!TIP]
> 想手绘更自由的图表，也可以用 Mermaid 的 `mindmap` 语法，见 [[02-编辑器/05-Mermaid图表]]。
