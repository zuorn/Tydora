# 编辑器行为与渲染

本页说明 Tydora 编辑器的**渲染能力与编辑行为**分别由哪些设置控制、在哪里调整。

> [!NOTE]
> 设置面板的页签为：通用、主题、快捷键、图像、思维导图、关系图谱、白板、终端、发布、Vim 模式、关于。**没有独立的「编辑器」页签**——编辑相关配置分布在「通用」与「主题」两个标签中。

## 渲染开关

以下能力在 Tydora 中**默认开启**，目前没有对应的界面开关（写在配置文件中恒为开启）：

| 能力 | 说明 |
| --- | --- |
| 数学公式 | KaTeX 渲染，行内 `$...$` 与块级 `$$...$$`。见 [[02-编辑器/04-数学公式]] |
| Mermaid 图表 | `mermaid` 代码块实时渲染。见 [[02-编辑器/05-Mermaid图表]] |
| Callout 提示块 | 15 种 `[!TYPE]` 提示块。见 [[02-编辑器/06-Callout块]] |
| Frontmatter | 顶部 YAML 元数据块的内联编辑与高亮。见 [[02-编辑器/07-Frontmatter]] |
| WikiLink | `[[笔记名]]` 双向链接与自动补全。见 [[03-知识管理/01-Wiki链接]] |
| 表格浮动工具栏 | 光标进入表格时浮现的工具栏。见 [[02-编辑器/08-表格操作]] |
| 标签 | `#标签` 内联标签与自动补全。见 [[03-知识管理/06-标签]] |

> [!NOTE]
> 这些能力的技术配置项存在于应用内部设置中（存储于 `localStorage` 的 `zmd-editor-settings`），但设置面板暂未提供开关界面。如你确实需要关闭某项能力，欢迎到 GitHub Issues 反馈需求。

## 编辑行为说明

### 默认编辑模式

打开文件时默认进入**即时渲染（IR）**模式。目前没有「默认编辑模式」的界面设置项；如需以源码模式开始，打开文件后按 `Ctrl+/` 切换。详见 [[02-编辑器/01-编辑模式]]。

### 字数统计

编辑器底部状态栏**始终显示当前文档的字数**，无需开启。分屏时只统计当前激活窗格。

### 关于缓存

Tydora **没有**「清除缓存」按钮。若遇到渲染异常（样式不刷新、图表不更新），可按以下顺序处理：

1. 切换一次编辑模式（`Ctrl+/`）强制重绘
2. 完全退出并重启 Tydora
3. 到 GitHub Issues 反馈并附上截图

### 关于 XSS 过滤

Tydora **没有**独立的「XSS 过滤」开关。Markdown 渲染走本地管线，WikiLink 等生成的 HTML 属性值会做转义处理；但打开来源不可信的 Markdown 文件时仍建议保持警惕。
