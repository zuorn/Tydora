# 大纲面板

侧栏的「大纲」页签显示**当前文档的标题结构**，让你一眼看清文章骨架，并随手跳转到任意章节。它同时还承担了「当前笔记的关系概览」职责，顶部会按需显示局部图谱与链接引用。

> [!NOTE]
> 「大纲」是侧栏的五个页签之一（文件 / 搜索 / 大纲 / 书签 / 标签），默认分配在**右侧栏**。

## 面板结构

打开「大纲」页签后，页面按当前笔记的情况从上到下显示若干分区：

| 分区 | 内容 | 何时显示 |
| --- | --- | --- |
| **Graph** | 当前笔记的**局部图谱**（深度 1 邻域：当前笔记 + 直接邻居 + 它们之间的连线） | 笔记有出链或入链时 |
| **On this page** | 当前笔记的**标题大纲** | 始终显示 |
| **Linked references** | 当前笔记里的 **WikiLink 出链**列表（按出现顺序去重） | 笔记含有 `[[...]]` 出链时 |

> 局部图谱与链接引用的用法见 [[03-知识管理/03-反向链接]]。

## 大纲（On this page）

### 功能说明

- 自动解析 Markdown 标题（1–6 级）
- 按标题层级**缩进展示**，结构一目了然
- 点击任意标题，编辑器滚动到对应位置
- 文档没有标题时显示「使用 # 标题语法来创建大纲」的引导

### 标题层级

大纲支持全部 6 级标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## Graph 分区

分区标题栏有两个按钮：

| 按钮 | 说明 |
| --- | --- |
| 展开 / 收起局部图谱 | 在侧栏内展开一张当前笔记的邻域小图 |
| 打开全局图谱 | 打开完整的 [[03-知识管理/04-知识图谱]] |

> [!TIP]
> 如果笔记既没有出链也没人引用它（孤立笔记），Graph 分区会整段隐藏——这本身就是一个「该补链了」的信号。

## 启动时自动展开

在 [[07-设置/01-通用设置]] 的「行为」分组中开启「启动时展开大纲」后，双击 `.md` 文件用本应用打开时，侧栏会自动展开并切换到大纲视图。

## 使用场景

- **长文档导航**：动辄数千字时，靠大纲比滚动高效得多
- **查看结构**：写作前先列大纲，写作中随时核对章节完整性
- **跳转章节**：点击即达，不必手动翻找

> [!TIP]
> 大纲看「单篇结构」，[[03-知识管理/04-知识图谱]] 看「笔记之间的关系」，两者互补。
