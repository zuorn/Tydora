# 白板设置

白板设置控制**新建白板文件的存放位置**与**画布交互行为**，让无限画布既能「随手记」，也能「精细排版」。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「白板」标签。白板本身的用法见 [[08-高级功能/03-白板画布]]。

## 新建白板的默认位置

设置通过「新建白板」创建 `.canvas` 文件时存放在哪里：

| 选项 | 说明 |
| --- | --- |
| 仓库的根目录 | 所有白板都放在仓库根目录下 |
| 当前文件所在的文件夹 | 就近存放，与相关笔记放在一起 |
| 指定附件文件夹 | 统一放到你指定的目录（需填写「附件文件夹路径」，路径相对于仓库根目录） |

> [!TIP]
> 白板常作为「索引 / 看板」使用，放在仓库根目录最方便定位；如果白板总是服务于某组笔记，用「当前文件所在的文件夹」更顺手。

## 对齐与吸附

| 设置项 | 说明 |
| --- | --- |
| 对齐网格 | 移动和缩放卡片时对齐背景网格 |
| 网格大小 | 网格的粒度 |
| 对齐物体 | 移动和缩放卡片时对齐邻近物体（出现对齐参考线） |

> [!TIP]
> 需要精确排布时打开「对齐网格」，自由摆放时打开「对齐物体」即可——后者会让卡片自动与其他卡片边缘对齐。

## 性能与视图

| 设置项 | 说明 |
| --- | --- |
| 隐藏卡片内容的缩放阈值 | 缩放到该阈值以下时隐藏卡片内容，只显示轮廓。数值越小越省性能，但内容会更快消失 |
| 启用小地图 | 在白板角落显示小地图导航 |
| 小地图位置 | 左上角 / 左下角 / 右下角 |

## 缩放范围

| 设置项 | 说明 |
| --- | --- |
| 最小缩放 | 允许缩小的下限 |
| 最大缩放 | 允许放大的上限 |
