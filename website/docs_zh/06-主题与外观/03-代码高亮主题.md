# 代码高亮主题

代码块的配色**独立于应用主题**，可在 11 款高亮主题中自由选择，让代码既清晰又养眼。

> [!NOTE]
> 代码高亮由 highlight.js 驱动，代码块语言选择器覆盖 30 种语言（见 [[02-编辑器/03-代码块]]）。

## 可用主题

### 浅色主题（4 款）

- **GitHub Light** —— GitHub 风格浅色（默认浅色主题）
- **Atom One Light** —— Atom 编辑器经典浅色
- **VS Code Light** —— VS Code 默认浅色
- **Solarized Light** —— Solarized 浅色配色

### 深色主题（7 款）

- **GitHub Dark** —— GitHub 风格深色（默认深色主题）
- **Atom One Dark** —— Atom 编辑器经典深色
- **VS Code Dark** —— VS Code 默认深色
- **Nord** —— 北欧冷色调
- **Monokai** —— 经典 Monokai
- **Dracula** —— 吸血鬼风格深色
- **Solarized Dark** —— Solarized 深色配色

## 切换主题

1. 打开设置（`Ctrl+,`）。
2. 切换到「主题」标签。
3. 在「代码高亮主题」区域点击色块即可应用。

> [!TIP]
> 除了设置面板，也可以在代码块工具栏上点「主题」按钮，就地切换当前的高亮配色。

## 跟随应用主题

默认情况下，代码高亮主题**跟随应用外观**自动在浅 / 深之间切换：

- 应用为浅色 → 使用你设定的浅色代码主题（默认 GitHub Light）
- 应用为深色 → 使用你设定的深色代码主题（默认 GitHub Dark）

在「代码高亮主题」区域选择「跟随应用主题」即可启用该行为；也可以分别指定浅色主题与深色主题，让两套外观各用各的配色。详见 [[06-主题与外观/01-内置主题]] 的「浅色偏好 / 深色偏好」。

> [!TIP]
> 若你常年在深色应用主题下写作，建议直接指定一款深色高亮主题，避免浅色代码块在暗背景下刺眼。

## 自定义代码主题

代码主题同样可以自定义：

| 操作 | 说明 |
| --- | --- |
| 复制并编辑 | 内置代码主题只读；点击「复制并编辑」可基于它创建一份可改色的副本 |
| 导入代码主题 | 选择代码主题文件导入第三方配色 |
| 重命名 / 删除 | 自定义代码主题支持重命名与删除（删除前会确认） |

编辑界面提供 JavaScript、Python、CSS、C++、Rust 等语言的**实时高亮预览**，并可按「语法高亮颜色」分组调整关键字、字符串、注释、数字、内置 / 运算符的颜色。
