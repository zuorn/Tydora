# 嵌入内容

嵌入（Embed）让你把**图片或白板**直接显示在当前笔记中，而不是只放一个跳转链接。常用于集中管理图片、把素材贴在正文旁。

> [!NOTE]
> 语法是在 Wiki 链接前加 `!`：`![[文件名]]`。Tydora 支持的是 **Obsidian 风格的图片嵌入**。

## 嵌入图片

```markdown
![[图片.png]]
```

仓库中的图片会**直接内联显示**在当前位置。解析规则：

1. 先按**文件名**在仓库中查找（大小写不敏感）
2. 找不到时，再按相对当前文件的路径解析
3. 也支持以 `/` 开头的仓库根路径，如 `![[/assets/图片.png]]`

### 指定宽度

在文件名后用 `|` 指定显示宽度（像素）：

```markdown
![[图片.png|400]]
```

> [!TIP]
> 在即时渲染模式下，也可以直接拖拽图片边缘调整大小，宽度会同步写回 `![[...|宽度]]` 语法。

## 标准 Markdown 图片

除了 Wiki 嵌入语法，标准写法同样可用：

```markdown
![图片描述](assets/图片.png)
```

> 两种写法的区别：`![[图片.png]]` 按**文件名**在仓库内查找，移动笔记后依然能找到；`![](相对路径)` 依赖路径，路径变了就失效。跨目录引用图片时推荐用 Wiki 嵌入语法。

## 悬停预览笔记

把鼠标移到任意 `[[WikiLink]]` 上，会弹出**预览卡片**：

- 普通笔记：显示渲染后的正文
- `.canvas` 白板文件：显示缩略图
- 目标不存在时给出提示

预览卡片支持嵌套悬停，可以顺着链接一路看下去，不必真的打开文件。详见 [[03-知识管理/01-Wiki链接]]。

## 使用场景

- **集中管理图片**：图片统一放在 `assets/`，正文用 `![[图片.png]]` 引用
- **素材就近展示**：写教程时把截图直接贴在对应步骤旁
- **白板速览**：用悬停预览快速回看某个白板的结构

## 注意事项

- 目前**不会**把 `![[笔记名]]` 展开为另一篇笔记的正文——嵌入笔记内容请改用悬停预览，或直接使用 `[[笔记名]]` 跳转
- 视频、音频、PDF 请用标准链接打开预览（见 [[04-文件管理/04-文件预览]]），不支持内联播放
- 图片的存储位置与命名规则由 [[07-设置/06-图片设置]] 决定
