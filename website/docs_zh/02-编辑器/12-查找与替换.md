# 查找与替换

Tydora 提供当前文档内的查找与替换，面板浮动在编辑区上方，支持实时计数与高亮定位。

> [!NOTE]
> `Ctrl+F` 打开查找，`Ctrl+H` 打开查找并展开替换行。

## 查找

1. 按 `Ctrl+F`，面板浮现在编辑区上方。
2. 输入关键词，正文中所有匹配项会立即高亮，并显示 `当前序号 / 总匹配数`。
3. 用「上一个匹配 / 下一个匹配」按钮在结果间跳转，编辑器会滚动到对应位置。
4. 按 `Esc` 或点「关闭」退出，高亮随之清除。

## 替换

1. 按 `Ctrl+H` 打开面板（或点击面板左侧的展开箭头，把查找面板展开为替换面板）。
2. 在「替换为...」输入框中填写替换文本。
3. 点击**替换**替换当前匹配项，点击**全部替换**一次性替换文档内所有匹配。

> [!TIP]
> 面板展开后，按 `Enter` 会替换当前项并跳到下一个，适合逐个确认的场景；需要批量处理时直接用「全部替换」。

## 行为说明

| 项目 | 说明 |
| --- | --- |
| 作用范围 | **仅当前文档**，不会跨文件搜索 |
| 匹配方式 | 字面文本匹配，区分大小写 |
| 正则表达式 | 不支持 |
| 高亮 | 匹配项在正文中高亮显示，关闭面板后清除 |
| 编辑模式 | 即时渲染（IR）与源码（SV）模式均可使用 |

> [!NOTE]
> 想在整个仓库中搜索文件名或正文内容，请使用侧栏的「搜索」页签；只想按文件名快速跳转，用 `Ctrl+O` 快速打开。详见 [[05-导航与搜索/01-快速打开]] 与 [[03-知识管理/05-链接索引]]。
