# 通用设置

通用设置管理应用的**字体、排版、编辑行为、窗口表现、侧栏分配与界面语言**，是每次安装后最先该看一眼的地方。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，默认停在「通用」标签。外观模式（浅色 / 深色）在「主题」标签中设置，见 [[06-主题与外观/01-内置主题]]。

## 外观

### 编辑器字体

选择正文与 Markdown 源码使用的字体。字体选择器支持搜索，并按来源分组：

| 分组 | 说明 |
| --- | --- |
| 内置 | Tydora 内置字体（如霞鹜文楷，适合中文写作） |
| 等宽字体 | 适合代码与表格对齐的等宽字体 |
| 系统字体 | 系统已安装的字体，可搜索筛选 |
| 系统默认 | 使用操作系统的默认字体 |

### 代码字体

单独设置代码块与行内代码使用的**等宽字体**。

### 字号

- **正文字号**：编辑器正文与 Markdown 源码的字号
- **代码字号**：代码块与行内代码的字号（默认 14）

### 行间距与段间距

- **行间距**：正文行高（默认 1.6）
- **段间距**：段落之间的上下间距（默认 0.5 em）
- **代码行间距**：代码块内文字的行高（默认 1.5）

### 预览区域宽度

编辑器内容区域的最大宽度（默认 800 px）。调小可让长文更易读，调大适合宽屏与表格较多的文档。

### 显示行号

在即时渲染（IR）模式下显示编辑器行号，默认开启。

### 代码块工具栏

选择代码块语言选择器与操作按钮的显示样式：

- **浮动（精简）** —— 只在右上角显示语言选择器（默认）
- **顶栏（含复制/删除）** —— 顶部完整工具栏

### 菜单项高度

调整右键菜单、下拉菜单等条目的垂直间距：紧凑 / 标准 / 宽松。

## 行为

### 自动保存

编辑时自动保存文件，**默认开启**。开启后，停止输入约 1 秒即写入磁盘；`Ctrl+S` 仍可立即保存。

> [!NOTE]
> 自动保存的延迟固定为 1 秒，没有可调的延迟设置。

### 启动时展开大纲

开启后，双击 `.md` 文件用本应用打开时，侧栏会自动展开并切换到大纲视图；关闭则保持折叠侧栏的原行为。

### 语言

界面显示语言，支持：

- **简体中文**
- **English**

切换后立即生效，无需重启。

### 匿名使用统计

「陪你走得更远 🌿」开关。开启后匿名收集功能使用情况与出错信息以改进产品：

- 只上报行为事件名与少量属性
- **绝不收集**文件路径、文件名、文档内容
- 可随时关闭，关闭后不再发送任何数据

详见 [[01-开始使用/隐私策略]]。

## 窗口

| 设置项 | 说明 |
| --- | --- |
| 展开侧栏时隐藏顶部栏 | 侧栏展开时顶部栏也自动隐藏，鼠标悬停顶部边缘可临时显示 |
| 折叠侧栏时隐藏顶部栏 | 折叠侧栏时顶部栏是否一并隐藏；关闭后折叠侧栏时顶部栏保持可见 |

> 窗口的位置与大小由 Tydora 自动记忆并在下次启动时恢复，无需手动配置。

## 侧栏设置

配置每个侧栏页签显示在**左侧栏**还是**右侧栏**：

| 页签 | 默认位置 |
| --- | --- |
| 文件 | 左侧栏 |
| 搜索 | 左侧栏 |
| 大纲 | 右侧栏 |
| 书签 | 左侧栏 |
| 标签 | 右侧栏 |

> [!TIP]
> 也可以直接在侧栏里**拖动页签**把它移到另一侧；设置中的配置会同步更新。
