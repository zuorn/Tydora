# 文件预览

除了 Markdown，Tydora 还支持直接预览多种图片、视频、音频与 PDF 文件，无需离开应用就能查看素材。

## 支持的格式

### 图片

JPG、JPEG、PNG、GIF、WebP、BMP、ICO、SVG、AVIF、HEIC、HEIF

### 视频

MP4、WebM、OGG、MOV、AVI、MKV、WMV、FLV、M4V

### 音频

MP3、WAV、OGG、FLAC、AAC、M4A、WMA

### 文档

PDF

> [!NOTE]
> 其他类型会显示「无法预览此类型文件」，并提示使用外部程序打开。

## 如何预览

- 在文件树中**点击**非 Markdown 文件，即会在主区域打开预览。
- `.canvas` 白板文件不会被预览接管，而是直接打开白板编辑器（见 [[08-高级功能/03-白板画布]]）。
- 在笔记中通过 `![[图片.png]]` 嵌入的图片会直接显示在正文里（见 [[03-知识管理/02-嵌入内容]]）。

## 图片预览

- **滚轮缩放**：缩放比例限制在 10% \~ 500%
- **缩放指示**：右上角显示当前百分比
- **重置缩放**：一键回到 100%
- **返回**：左上角「◀ 返回」按钮关闭预览
- 支持透明背景显示（PNG / WebP / SVG）

## 视频预览

使用内置播放器（`<video>`）：

- 播放 / 暂停、进度拖动、音量控制
- 支持浏览器原生支持的编码格式；不支持的编码会提示加载失败

## 音频预览

使用内置播放器（`<audio>`）：播放 / 暂停与进度控制。

## PDF 预览

以内嵌方式加载 PDF 文件，可直接翻页与缩放。适合在笔记旁对照资料。

> [!NOTE]
> 图片的存储位置与命名规则可在 [[07-设置/06-图片设置]] 中配置。
