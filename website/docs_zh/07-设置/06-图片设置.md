# 图片设置

图片设置决定粘贴或拖入图片时的**存储位置与命名规则**，让你在「随仓库管理」与「集中存放」之间自由选择。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「图像」标签。

## 存储位置

### 仓库 assets 目录（默认）

图片保存在**当前仓库根目录下的 `assets/` 文件夹**中。

- 优点：图片随仓库一起管理、移动、备份，链接不易失效
- 缺点：仓库体积会随图片增多而变大

配套选项：

| 选项 | 说明 |
| --- | --- |
| 自动创建 assets 目录 | 目录不存在时自动创建（默认开启） |

### 固定本地目录

图片保存在**固定的本地目录**中，与具体仓库解耦。

- 优点：多个仓库可共用同一图库
- 缺点：路径依赖本地环境，换机器或移动目录后可能失效

选择该模式后，需要在「存储路径」中指定目录（可通过「选择目录...」按钮挑选）。

### 图床上传（后续支持）

图床模式目前**尚未实现**，设置中会显示「图床上传（后续支持）」并给出提示。当前请使用前两种本地存储方式。

## 文件命名格式

设置粘贴图片时自动生成的文件名：

| 格式 | 示例 | 说明 |
| --- | --- | --- |
| 原始名称 | `截图.png` | 保留图片本来的文件名 |
| 时间戳 | `20240101120000.png` | 按时间唯一命名 |
| 原始名称 + 时间戳（默认） | `截图-20240101120000.png` | 既保留语义又避免重名 |

> [!TIP]
> 多人协作或需溯源时用「原始名称」更直观；个人笔记推荐默认的「原始名称 + 时间戳」，可避免同名图片互相覆盖。

## 支持的格式

粘贴与拖拽识别以下图片格式：

PNG、JPG / JPEG、GIF、WebP、BMP、SVG、AVIF、ICO
