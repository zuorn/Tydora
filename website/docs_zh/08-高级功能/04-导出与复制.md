# 导出与复制

写好一篇笔记后，Tydora 提供多种**导出与复制**方式，把内容带到文档、图片或社交平台。所有命令都可以在命令面板（`Ctrl+P`）的「导出」分类中找到，也可以从编辑器顶部的「复制和导出」入口打开。

> [!NOTE]
> 导出依赖编辑器的**渲染结果**，因此需要在**即时渲染（IR）模式**下执行。源码模式下部分导出会失败，按 `Ctrl+/` 切到 IR 即可。

## 格式一览

| 格式 | 输出 | 说明 |
| --- | --- | --- |
| **Markdown** | 复制到剪贴板 | 复制原始 Markdown 文本，可直接粘贴到其他编辑器 |
| **公众号** | 复制到剪贴板 | 复制为适合微信公众号编辑器的 HTML 富文本，图片会一并处理 |
| **PDF** | 文件 | 生成 PDF 文档 |
| **长图（PNG）** | 文件 | 把整篇笔记渲染为一张长图 |
| **HTML** | 文件 | 生成自包含的 HTML 文档，样式内联、图片内联，单文件即可分享 |
| **Word（docx）** | 文件 | 生成 Word 文档；导出时强制使用浅色主题，Mermaid 图表会栅格化为图片 |
| **图文卡片（小红书）** | 图片组 | 按卡片分页排版，生成一组适合社交平台发布的图片 |

## 使用流程

1. 按 `Ctrl+P` 打开命令面板，搜索「导出」或直接输入目标格式（如 `pdf`、`word`、`小红书`）。
2. 选择对应命令。
3. 弹出预览窗口，可先查看效果：
   - **复制到剪贴板** —— 适合 Markdown / 公众号这类「直接粘贴」的格式
   - **保存** —— 选择保存位置并写入文件
4. 保存成功后可在对话框中看到保存路径。

> [!TIP]
> 编辑器顶部工具栏的「复制和导出」按钮提供同样的格式列表，适合鼠标操作；常用项还可以**固定到工具栏**，一键直达。

## 各格式细节

### Markdown / 公众号

这两种格式**不写文件**，只把内容放进剪贴板：

- **Markdown**：原始 Markdown 文本
- **公众号**：渲染后的富文本，粘贴到公众号编辑器即可保留样式

### HTML

生成**自包含**的单个 HTML 文件：

- 样式全部内联，不依赖外部 CSS
- 图片会被内联为 data URL
- 适合作为附件发送，或上传到任意静态空间

### PDF / 长图

- **PDF**：适合打印与正式归档
- **长图**：整篇笔记渲染成一张 PNG，适合在聊天工具或社交平台分享长文

### Word

导出 Word 时会做几项适配：

- 强制使用浅色主题，避免深色背景在 Word 中难以阅读
- Mermaid 图表会**栅格化**为图片，保证在 Word 中正常显示
- 任务列表的复选框会替换为图形，避免丢失勾选状态

### 图文卡片

按内容自动**分页排版**成多张卡片，导出为一组图片文件（文件名带序号），适合发布到图文平台。
