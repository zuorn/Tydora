# 终端

Tydora 内置了一个**真实终端**，基于 xterm.js 渲染、由 Rust 侧创建 PTY 会话。它不是一个只读的命令回显窗口——你可以在里面运行交互式程序，边写笔记边跑命令、看构建输出。

> [!NOTE]
> 终端以**编辑器窗格**的形式存在，不是独立窗口。快捷键：``Ctrl+` `` 新建终端窗格。

## 打开终端

| 入口 | 说明 |
| --- | --- |
| ``Ctrl+` `` | 新建一个终端窗格 |
| 文件树右键 →「在终端打开」 | 在该文件所在目录打开终端 |
| 命令面板（`Ctrl+P`）→「新建终端」 | 同快捷键 |
| 编辑器「更多」菜单 →「新建终端」 | 同快捷键 |

## 使用哪个 shell

Tydora 会自动探测系统上可用的 shell：

| 平台 | 规则 |
| --- | --- |
| Windows | 优先 `pwsh.exe`（PowerShell 7+），找不到时回退 `cmd.exe` |
| macOS / Linux | 使用 `$SHELL` 环境变量，未设置时回退 `bash` |

> [!NOTE]
> 终端会话使用你本机的 shell，权限与行为等同于你在系统终端里直接操作。

## 界面能力

| 能力 | 说明 |
| --- | --- |
| 真实交互 | 支持需要 TTY 的交互式程序（分页器、进度条、颜色输出等） |
| 智能标题 | 通过 shell 的 OSC 转义序列解析当前运行的命令与工作目录，显示在窗格标题上 |
| 查找 | 终端内查找文本，支持上一个 / 下一个、区分大小写、无匹配提示 |
| 右键菜单 | 复制、粘贴、查找、拆分窗格（左右 / 上下）、关闭标签页 |
| 字号缩放 | 在终端内按住 `Ctrl` 滚动鼠标滚轮即可缩放 |

## 分屏与布局

终端可以参与编辑区的分屏布局：

- 与编辑器窗格并排（`Ctrl+\` 左右分屏、`Ctrl+-` 上下分屏）
- 终端之间再分屏
- 拖动窗格之间的分隔线调整大小
- 每个终端窗格拥有**独立的 shell 会话**

> [!NOTE]
> 目前每个窗格对应一个会话，没有「多标签页」的概念；需要多个会话时，多开几个终端窗格即可。详见 [[05-导航与搜索/04-分屏与多窗格]]。

## 终端设置

在 [[07-设置/08-终端设置]] 的「终端」标签中配置：

| 设置项 | 说明 |
| --- | --- |
| 配色方案 | 「自动」跟随应用主题，另有 11 种预设（Campbell、Solarized、Dracula、Retro 等） |
| 字体 | 预设等宽字体或自定义 CSS `font-family` |
| 字号 | 8 \~ 40，默认 13 |

> [!TIP]
> 修改设置后，已经打开的终端会**实时热更新**配色与字号，不需要重开。

## 使用场景

- 在笔记目录里跑 `git status`、`git commit`
- 用构建工具处理笔记中的素材（图片压缩、格式转换）
- 执行 `npm` / `cargo` 等命令并实时查看输出
- 配合 [[08-高级功能/04-导出与复制]]，把命令输出直接记进笔记
