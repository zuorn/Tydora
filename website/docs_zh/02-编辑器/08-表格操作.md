# 表格操作

Tydora 提供便捷的表格编辑能力：既可以用标准 Markdown 语法书写，也可以在即时渲染模式下通过浮动工具栏可视化增删行列、调整对齐、合并单元格。

> [!NOTE]
> 插入表格快捷键：`Ctrl+T`。在即时渲染模式下，把光标放入表格会出现浮动工具栏。

## 创建表格

### 方法一：Markdown 语法

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

### 方法二：快捷键

按 `Ctrl+T` 插入一个默认大小的表格。

### 方法三：右键菜单

1. 在编辑区右键点击。
2. 选择「插入」→「表格」。

## 表格浮动工具栏

在即时渲染模式下，把光标放入表格即可唤出浮动工具栏，包含：

| 按钮 | 说明 |
| --- | --- |
| 调整表格大小 | 以网格选择器调整行列数 |
| 左对齐 / 居中对齐 / 右对齐 | 设置当前列对齐方式 |
| 上方插入行 / 下方插入行 | 增行 |
| 左侧插入列 / 右侧插入列 | 增列 |
| 删除行 / 删除列 | 删行删列 |
| 合并单元格 / 拆分单元格 | 合并或拆分选中单元格 |
| 删除表格 | 移除整张表格 |
| 更多操作 | 展开其余操作 |

> [!TIP]在单元格内按 `Tab` 会跳到下一格，在最后一格按 `Tab` 会自动新增一行，连续录入时非常顺手。

## 增删行列快捷键

| 操作 | 快捷键 |
| --- | --- |
| 在上方插入行 | `Ctrl+Shift+F` |
| 在下方插入行 | `Ctrl+Shift+.` |
| 在左侧插入列 | `Ctrl+Shift+G` |
| 在右侧插入列 | `Ctrl+Shift+=` |
| 删除行 | `Ctrl+-` |
| 删除列 | `Ctrl+Shift+-` |

> [!NOTE]`Ctrl+-` 同时是「上下分屏」的快捷键。焦点在表格内时优先执行删除行，焦点在表格外时执行分屏。若你更常用分屏，可在 [[07-设置/03-快捷键设置]] 中调整其中之一。

## 单元格对齐

在 Markdown 分隔行中用冒号设置对齐方式：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 内容   | 内容    | 内容   |
```

快捷键：

| 对齐方式 | 快捷键 |
| --- | --- |
| 左对齐 | `Ctrl+Shift+L` |
| 居中对齐 | `Ctrl+Shift+C` |
| 右对齐 | `Ctrl+Shift+R` |

## 在源码模式下调整

源码模式下直接编辑管道符表格即可；`Tab` / `Shift+Tab` 可在单元格间移动。列宽不会自动对齐，如需整齐的管道符排版，可在即时渲染模式下用浮动工具栏增列，再回到源码模式微调。
