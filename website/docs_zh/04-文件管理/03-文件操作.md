# 文件操作

Tydora 在文件树与编辑器中提供完整的文件管理能力：新建、重命名、删除、移动、复制、在终端打开等。

> [!NOTE]绝大多数操作可通过文件树右键菜单完成。详见 [[04-文件管理/02-文件树]]。

## 新建

### 新建文件

1. 在文件树中右键点击目标目录（或根目录），选择「新建文件」。
2. 输入文件名，例如 `笔记.md`（`.md` 可省略，Tydora 自动补上）。
3. 按 `Enter` 确认，编辑器随即打开新文件。

### 新建文件夹

右键 →「新建文件夹」→ 输入名称 → `Enter`。

### 新建白板

右键 →「新建白板」→ 输入名称，创建 `.canvas` 文件并在主区域打开白板。白板的默认存放位置可在 [[07-设置/07-白板设置]] 中配置。

> [!TIP]同名文件 / 文件夹已存在时，Tydora 会自动生成不冲突的名称，不会覆盖已有内容。

## 重命名

1. 右键点击文件或文件夹 →「重命名」。
2. 文件名变为内联可编辑状态。
3. 输入新名称，按 `Enter` 确认（`Esc` 取消）。

> [!TIP]重命名笔记文件后，Tydora 会**自动重写**指向它的 `[[WikiLink]]`，让链接不失效。详见 [[03-知识管理/05-链接索引]]。

## 删除

1. 右键点击文件或文件夹 →「删除」。
2. 在确认对话框中确认。多选时对话框会显示待删除的项目数量。

> [!WARNING]删除操作**不可撤销**，不走系统回收站，且会递归删除文件夹内全部内容。重要文件建议先备份或纳入版本管理。

## 移动到其他目录

1. 右键 →「移动到...」。
2. 在弹出的目录选择器中选择目标文件夹。
3. 确认后文件被移动，指向它的 WikiLink 会同步修复。

也可以直接在文件树中**拖拽**文件或文件夹到目标目录。

## 复制

右键菜单的「复制」包含两个子项：

| 子项 | 效果 |
| --- | --- |
| 创建副本 | 在**同一目录**生成一份副本（自动处理重名） |
| 复制到剪切板 | 把文件本身复制到系统剪贴板，可在系统文件管理器中粘贴 |

## 复制路径

右键 →「复制路径」，把文件 / 文件夹的完整路径写入剪贴板，便于在终端、发布配置或对话中引用。

## 在终端打开

右键 →「在终端打开」，在该文件所在目录打开一个 [[08-高级功能/05-终端]] 窗格，适合需要命令行处理素材的场景。

## 打开文件位置

右键 →「打开文件位置」，在系统文件管理器中定位并选中该文件。

## 在新窗口 / 新面板打开

| 命令 | 效果 |
| --- | --- |
| 在新面板打开 | 在当前窗口内新增一个编辑器窗格（仅 Markdown 文件可用） |
| 在新窗口中打开 | 打开一个独立的编辑器窗口 |

> 分屏与窗格管理的细节见 [[05-导航与搜索/04-分屏与多窗格]]。

## 保存

- 手动保存：`Ctrl+S`
- 自动保存：默认开启，停止输入约 1 秒后自动写入磁盘（可在 [[07-设置/01-通用设置]] 的「行为」分组关闭）

> [!NOTE]未保存的文件（如通过「另存为」流程新建）在关闭窗口时会提示保存、不保存或取消。
