# 自定义主题

内置主题不满足你的审美时，Tydora 允许你**自建主题**、**导入主题包**，或把内置主题复制一份后逐项改色。自定义主题同样支持浅色 / 深色两套偏好。

> [!NOTE]
> 主题相关操作都在设置的「主题」标签中完成。Tydora **不支持导入 Typora 主题**；自定义主题有两种来源：在应用内编辑，或导入 Tydora 自己的主题包。

## 创建自定义主题

### 方式一：从内置主题复制

1. 在「内置主题」区找到想要改造的主题。
2. 悬停卡片，点击「复制并编辑」。
3. Tydora 会创建一个名为「原主题名（自定义）」的副本，并进入编辑界面。

> [!NOTE]
> 内置主题是只读的，必须先复制才能修改颜色。

### 方式二：新建空白主题

在「自定义主题」区点击「新建主题」，直接进入编辑界面逐项配色。

## 编辑主题

主题编辑器按语义分组暴露颜色变量，每组都有实时预览：

| 分组 | 包含内容 |
| --- | --- |
| 界面 | 主背景、侧栏 / 次级背景、浮层 / 卡片、悬停背景、输入框背景、边框、侧栏控件不透明度 |
| 正文 | 正文、次要文字、提示文字、粗体 / 强调、主题色及其悬停态 |
| 代码块 | 代码块背景与圆角 |
| 行内代码 | 背景、文字、圆角、内边距 |
| 引用块 | 左边色块、背景、文字、内边距 |
| Metadata / Frontmatter | 背景、边框、圆角 |
| 表格 | 表头背景、内容背景、圆角 |
| 标签 | 背景、文字、边框、圆角、内边距 |
| 滚动条 | 滑块、滑块悬停、轨道、圆角、宽度 |
| 语法高亮颜色 | 关键字、字符串、注释、数字、内置 / 运算符 |

编辑界面右侧提供**正文预览**，包含标题、粗体、行内代码、代码块、引用、表格、标签等典型元素的实时效果。

> [!TIP]
> 每个色块都支持取色器与手动输入色值；带透明度的变量（如主题色 RGB、侧栏控件不透明度）可单独调节 alpha。

## 导入 CSS 主题文件

点击「导入主题」→「选择主题文件」，可以导入一个 CSS 文件：

- 文件需包含 `:root` 或 `[data-theme=...]` 形式的 CSS 变量定义
- 至少需要定义 `--bg-primary`，否则会提示导入失败
- 导入后 Tydora 会解析其中的颜色变量、推断主题是浅色还是深色，并生成对应的预览色卡

> [!NOTE]
> 这是把「别处已有的 CSS 变量主题」搬进 Tydora 的方式，与 Typora 主题的变量命名并不通用。

## 主题包（整包导入导出）

主题包用于**备份或分享一整套配色**：

| 操作 | 说明 |
| --- | --- |
| 导出主题包 | 生成 `.tydora-theme.json` 文件，包含当前浅色 / 深色偏好下的**应用主题与代码主题共四套** |
| 导入主题包 | 选择 `.tydora-theme.json` 文件，一次性恢复四套配色 |

> [!TIP]
> 换电脑或重装系统前导出一份主题包，几分钟就能把配色环境完整还原。

## 重命名与删除

- **重命名**：在自定义主题卡片上选择「重命名」
- **删除**：选择「删除主题」，会弹出确认对话框（不可撤销）
