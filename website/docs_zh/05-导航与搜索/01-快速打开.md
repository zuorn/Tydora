# 快速打开

「快速打开」让你用键盘瞬间定位并打开仓库中的任意文件，是摆脱鼠标、提升导航效率的核心功能。

> [!NOTE]
> 快捷键：`Ctrl+O`。

## 使用方法

1. 按 `Ctrl+O` 打开快速打开面板。
2. 输入文件名关键词进行**模糊搜索**；面板打开时先展示**最近访问的文件**，不输入也能直接选。
3. 用上下方向键选择结果，按 `Enter` 打开；或直接点击结果。
4. 按 `Esc` 关闭面板。

## 两个搜索模式

面板顶部可以切换搜索目标：

| 模式 | 说明 |
| --- | --- |
| 搜索文件 | 在当前仓库内按文件名 / 路径模糊匹配 |
| 搜索知识库 | 在当前已添加的仓库之间检索与切换 |

## 模糊搜索

支持模糊匹配，无需输入完整文件名：

- 输入 `笔记` → 匹配 `我的笔记.md`、`笔记管理.md`
- 输入 `2024日` → 匹配 `2024年日记.md`
- 输入 `项目 readme` → 匹配 `项目/README.md`（跨层级也可匹配）

## 按标签筛选

输入框支持 `#标签 关键字` 语法：

```
#技术 缓存
```

会先取出携带 `#技术` 标签的文档集合，再按「缓存」过滤文件名与内容。详见 [[03-知识管理/06-标签]]。

> [!TIP]
> 搜索范围是**当前活跃仓库**内的全部文件。要搜其他仓库，先切换仓库（见 [[04-文件管理/01-仓库]]）。

## 最近访问的文件

面板打开时会显示**最近访问**列表，常用文件一触即达，不必每次都搜索。

## 直接分屏打开

在结果项上可以直接选择打开方式，无需先打开再分屏：

| 操作 | 效果 |
| --- | --- |
| 打开 | 在当前窗格打开 |
| 右侧分屏打开 | 新建一个左右分屏窗格并打开该文件 |
| 下方分屏打开 | 新建一个上下分屏窗格并打开该文件 |
| 新窗口打开 | 在独立窗口中打开 |

> 分屏的更多用法见 [[05-导航与搜索/04-分屏与多窗格]]。

## 与命令面板的关系

- **快速打开**（`Ctrl+O`）搜「文件」。
- **命令面板**（`Ctrl+P`）搜「命令」。

两者配合，几乎可以纯键盘完成所有操作。
