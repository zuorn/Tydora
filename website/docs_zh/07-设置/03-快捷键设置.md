# 快捷键设置

Tydora 内置 **48 项可自定义**的编辑快捷键。你可以在设置中查看全部绑定、修改为习惯的组合，或一键恢复默认。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「快捷键」标签。完整默认列表见 [[07-设置/04-快捷键速查]]。

## 快捷键分组

设置中的快捷键按功能分组，便于查找：

| 分组 | 项数 | 内容 |
| --- | --- | --- |
| 格式 | 9 | 加粗、斜体、删除线、行内代码、代码块、超链接、高亮、引用、水平分割线 |
| 列表 | 6 | 无序列表、有序列表、任务列表、增加 / 减少缩进、切换任务状态 |
| 标题 | 7 | 一 \~ 六级标题、段落 |
| 插入 | 3 | 表格、在上方插入、在下方插入 |
| 表格 | 9 | 插入 / 删除行列、单元格对齐 |
| 编辑 | 3 | 撤销、重做、全选（代码块内） |
| 视图 | 6 | 切换侧栏、打字机模式、打开思维导图、左右 / 上下分屏、新建终端 |
| 模式 | 1 | 模式切换（IR ↔ SV） |
| 系统 | 4 | 关闭提示、快速打开文件、命令面板、打开 / 关闭设置 |

> [!NOTE]
> 除上述 48 项外，还有几个**应用级快捷键**固定在程序里，不在设置面板中：`Ctrl+S`（保存）、`Ctrl+W`（关闭窗口）、`Ctrl+F`（查找）、`Ctrl+H`（替换）、`Ctrl+G`（知识图谱）。

## 自定义快捷键

1. 在快捷键列表中找到目标命令。
2. 点击当前的快捷键组合。
3. 按下新的组合键。
4. 自动保存，立即生效。

> [!TIP]
> 修改后无需重启，配置保存在本地，会随应用一起持久化。

## 重置快捷键

点击「重置」按钮，可将**所有**快捷键恢复为默认值。

## 冲突与让渡

### 应用内的组合键重叠

个别组合键在不同上下文中有两种含义，运行时按上下文决定：

| 快捷键 | 上下文 A | 上下文 B |
| --- | --- | --- |
| `Ctrl+-` | 表格内：删除行 | 表格外：上下分屏 |

> [!WARNING]
> 默认配置中「有序列表」**没有绑定任何快捷键**，`Ctrl+O` 只属于「快速打开文件」。若你希望用快捷键插入有序列表，请自行分配一个不冲突的组合。

### 与 Vim 模式的冲突

开启 [[02-编辑器/11-Vim模式]] 后，部分 App 快捷键与 Vim 键位冲突（如 `Ctrl+D`、`Ctrl+U`、`Ctrl+E`、`Ctrl+F`、`Ctrl+H`、`Ctrl+W`、`Ctrl+O`、`Ctrl+G`）。设置页的「Vim 模式」标签提供**逐项让渡开关**，可分别决定冲突键交给 Vim 还是留给 App。
