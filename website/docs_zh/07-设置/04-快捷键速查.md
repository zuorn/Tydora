# 快捷键速查表

Tydora 内置 48 项可自定义的编辑快捷键，下表为**默认配置**。所有快捷键都可以在 [[07-设置/03-快捷键设置]] 中查看、修改或重置为默认值。

> [!NOTE]
> 表中 Ctrl 在 macOS 上对应 Cmd（⌘）。

下列快捷键固定在程序中，不在快捷键设置面板里：

| 快捷键 | 功能 | 相关文档 |
| --- | --- | --- |
| `Ctrl+S` | 保存当前文件 | [[04-文件管理/03-文件操作]] |
| `Ctrl+W` | 关闭当前窗口 | — |
| `Ctrl+F` | 当前文档内查找 | [[02-编辑器/12-查找与替换]] |
| `Ctrl+H` | 当前文档内替换 | [[02-编辑器/12-查找与替换]] |
| `Ctrl+G` | 打开知识图谱 | [[03-知识管理/04-知识图谱]] |

## 关于快捷键重叠的说明

> [!WARNING]默认配置中存在两处组合键重叠，运行时按上下文区分：
> - **`Ctrl+-`**：焦点在表格内时执行「删除行」，在表格外时执行「上下分屏」。
> - **`Ctrl+E` / `Ctrl+D` / `Ctrl+U` 等**：开启 [[02-编辑器/11-Vim模式]] 后，在 normal / visual 模式下默认让渡给 Vim，此时 App 的同名快捷键不生效；可在「Vim 模式」设置页逐项改回。

> 所有可自定义快捷键均可在设置中修改，分配后即时生效。
