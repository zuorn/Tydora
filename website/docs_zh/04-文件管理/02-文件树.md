# 文件树

侧栏的**文件树**以树形结构展示当前仓库的目录与文件，是你浏览和管理笔记的主入口。

> [!NOTE]
> 「文件」是侧栏的五个页签之一（文件 / 搜索 / 大纲 / 书签 / 标签），可在设置中分配到左侧栏或右侧栏。

## 工具栏

文件树页签顶部提供：

| 按钮 | 说明 |
| --- | --- |
| 新建文件 | 在当前选中文件所在目录创建新文件 |
| 新建文件夹 | 在当前选中文件所在目录创建子文件夹 |
| 折叠全部 | 收起所有目录 |
| 展开全部 | 展开所有目录 |
| 定位当前文件 | 滚动并高亮到当前正在编辑的文件 |
| 排序 | 切换排序方式（见下） |

## 排序方式

点击排序按钮可在以下方式间切换，选择会被记住：

- 文件名（A-Z）
- 文件名（Z-A）
- 编辑时间（从新到旧）
- 编辑时间（从旧到新）
- 创建时间（从新到旧）
- 创建时间（从旧到新）

## 展开与折叠

- 点击目录前的**箭头**展开或折叠
- 工具栏的「折叠全部 / 展开全部」可一键批量操作

## 右键菜单

在文件、目录或空白处右键，菜单项略有不同：

### 文件

| 菜单项 | 说明 |
| --- | --- |
| 在新面板打开 | 在当前窗口的新窗格中打开 |
| 在新窗口中打开 | 在独立窗口中打开 |
| 新建文件 / 新建白板 / 新建文件夹 | 在同级创建 |
| 收藏 | 加入 [[03-知识管理/07-书签]] |
| 重命名 | 就地（内联）重命名 |
| 复制 | 子菜单：「创建副本」或「复制到剪切板」 |
| 移动到... | 移动到仓库内的其他目录 |
| 删除 | 删除文件（需确认） |
| 复制路径 | 复制文件的完整路径 |
| 在终端打开 | 在该文件所在目录打开 [[08-高级功能/05-终端]] |
| 打开文件位置 | 在系统文件管理器中定位该文件 |

### 文件夹

新建文件 / 新建白板 / 新建文件夹、收藏、重命名、移动到...、删除、复制路径、在终端打开、打开文件位置。

### 空白处

新建文件 / 新建白板 / 新建文件夹、复制路径、在终端打开、打开文件位置。

> [!WARNING]
> 删除文件夹会一并删除其中的所有内容，且**不可撤销**（不走系统回收站），请谨慎操作。

## 多选与批量操作

- 按住修饰键点击可**多选**文件
- 对多选项执行删除时，确认对话框会显示「确定要删除选中的 N 个项目吗？」

## 拖拽移动

1. 在文件树中按住文件或文件夹。
2. 拖拽到目标目录上（目标目录会高亮）。
3. 释放鼠标完成移动。

> [!NOTE]
> 移动或重命名后，Tydora 会重写指向它的 `[[WikiLink]]` 并刷新索引，尽量保持链接仍可正确解析。详见 [[03-知识管理/05-链接索引]]。

## 内联重命名

1. 右键选择「重命名」。
2. 文件名变为可编辑状态。
3. 输入新名称，按 `Enter` 确认（按 `Esc` 取消）。

> [!NOTE]
> 文件树没有绑定 `F2` 快捷键；开启 [[02-编辑器/11-Vim模式]] 后，可以在文件树中用 `r` 触发重命名。

## 侧栏搜索

文件树旁边的「搜索」页签提供全局搜索：输入关键词可检索**文件名与正文内容**，也支持 `#标签 关键字` 语法按标签筛选。详见 [[03-知识管理/06-标签]] 与 [[05-导航与搜索/01-快速打开]]。
