# 关于 Tydora

Tydora 是一款基于 Tauri v2 + React 19 构建的现代化桌面 Markdown 编辑器，支持 WYSIWYG 与源码双模式编辑、WikiLink 双向链接、标签与书签、知识图谱、思维导图、白板画布、内置终端与多格式导出。其名取自 *Type/Typography* 与古希腊语 *δῶρον（礼物）*，意为「指尖上的礼物」。

> [!NOTE]Tydora 是开源软件，采用 Apache License 2.0 许可证。欢迎在 GitHub 上提 Issue、参与讨论或贡献代码。

## 检查更新

Tydora 支持自动更新：启动时会在后台自动检查是否有新版本，若有则提示你下载安装。

手动检查步骤：

1. 打开设置（按 `Ctrl+,`）。
2. 切换到「关于」标签。
3. 点击「检查更新」。

> [!NOTE]不同分发渠道的更新方式不同：GitHub 版本：通过 Tauri 更新器读取 GitHub Releases 上的 latest.json 与 .sig 签名文件，下载并安装新版本。**微软商店版本：跟随商店更新；检测到 GitHub 上有更高版本时，「关于」页会提供一键切换到 GitHub 版本的选项（切换后改为通过 GitHub 更新）。**便携版：可通过便携版专用通道检查并安装更新。

> [!TIP]自动更新的签名密钥配置详见 （面向贡献者）。

## 功能特性一览

- **双模式编辑**：即时渲染（IR / WYSIWYG）+ 源码模式（SV），`Ctrl+/` 切换
- **Vim 模式**：LazyVim 风格键位、Leader 菜单、窗格导航（默认关闭，可在设置中开启）
- **多仓库管理**：基于文件夹的仓库，文件树支持排序、多选与拖拽
- **WikiLink 双向链接**：`[[笔记名]]` 语法，自动补全、别名、标题锚点、重命名自动修复
- **标签体系**：`#标签` 语法 + 标签列表与标签图谱，支持 `#标签 关键字` 全局筛选
- **书签**：收藏文件与文件夹，分组管理、拖拽排序
- **知识图谱**：WebGL 力导向图（D3.js 布局），可视化笔记关系
- **思维导图**：从 Markdown 标题层级自动生成，Markmap 驱动，支持导出 SVG / 复制图片
- **白板画布**：React Flow 无限画布，兼容 JSON Canvas（`.canvas`）格式，7 种节点类型
- **Callout 提示块**：15 种 GitHub 风格类型，支持折叠
- **Mermaid 图表**：流程图、时序图、甘特图等实时渲染
- **数学公式**：KaTeX 渲染 + 公式编辑弹窗（实时预览）
- **Frontmatter**：即时渲染模式内联编辑 YAML 元数据
- **查找与替换**：`Ctrl+F` / `Ctrl+H`
- **分屏与多窗格**：左右 / 上下分屏，编辑器与终端可自由组窗格
- **内置终端**：xterm.js + 真实 shell，12 种配色方案
- **导出与复制**：PDF、HTML、Word、长图、Markdown、公众号、图文卡片（小红书）
- **一键发布**：仓库发布为静态网站，内置预览服务器
- **主题系统**：10 款内置主题 + 自定义主题编辑与主题包导入导出
- **代码高亮**：11 款高亮配色，代码块语言选择器覆盖 30+ 语言
- **可定制快捷键**：48 项快捷键可在设置中重绑定
- **多语言界面**：简体中文 / English
- **多媒体预览**：图片、视频、音频、PDF

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 后端 | Rust（Tauri v2），仅承担 IPC 与文件 IO 网关 |
| 前端 | React 19 + TypeScript + Vite 6 |
| 编辑器 | TipTap 3.x（WYSIWYG）+ CodeMirror 6（源码） |
| 可视化 | D3.js（图谱布局）、markmap（思维导图）、Mermaid（图表）、React Flow（白板） |
| 终端 | xterm.js + Rust 侧 PTY |
| Tauri 插件 | fs / dialog / window-state / updater / process / clipboard-manager / single-instance |
