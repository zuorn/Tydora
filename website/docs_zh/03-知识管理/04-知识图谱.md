# 知识图谱

知识图谱用可视化方式呈现笔记之间的链接关系，帮你从「单篇笔记」跃升到「知识网络」的视角，发现结构、核心与孤岛。

> [!NOTE]
> 快捷键：`Ctrl+G`。图谱使用 **WebGL 渲染 + D3 力导向布局**，笔记数量上千也能流畅交互。

## 功能说明

- **力导向布局**：节点彼此吸引 / 排斥，自动聚拢成簇
- **节点大小反映链接数量**：公式为 `4 + min(8, √链接数 × 0.85)`，被引用越多节点越大
- **无链接的笔记显示为灰色**，一眼看出孤立节点
- **当前打开的笔记会高亮放大**，方便定位「我在哪」
- 支持缩放、拖拽、悬停高亮邻居、点击跳转

## 打开方式

按 `Ctrl+G` 打开图谱。其行为由设置决定（[[07-设置/05-思维导图设置]] 的「关系图谱」标签）：

- 开启「在新窗口中打开」→ 在独立 Tauri 窗口中显示，可放到副屏
- 关闭（默认）→ 在主区域以面板形式显示

也可以在命令面板（`Ctrl+P`）中搜索「打开知识图谱」，或在侧栏「大纲」页签的 Graph 分区标题栏点「打开全局图谱」。

## 图谱解读

### 节点

- 圆形大小表示该笔记的链接数量
- 被引用越多的笔记，节点越大，越可能是「核心笔记」
- 没有任何链接的笔记显示为灰色小点，散落在边缘
- 当前打开的笔记有高亮与放大效果

### 连线

- 表示笔记间的 [[03-知识管理/01-Wiki链接]] 关系
- 方向表示引用方向（A → B 表示 A 引用了 B）
- 连线透明度可在设置中调整

### 布局

- 力导向图会自动寻找平衡布局
- 关联密集的笔记聚成一簇
- 孤立（无链接）的笔记会被轻微地向中心收拢，避免飞出画布

## 交互操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 缩放视图（缩放范围有限制，避免过度放大 / 缩小） |
| 拖拽节点 | 移动单个节点，松手后重新参与力模拟 |
| 拖拽空白处 | 平移整个画布 |
| 悬停节点 | 高亮该节点及其直接邻居，其余节点淡化 |
| 点击节点 | 打开对应笔记 |

> [!TIP]
> 悬停高亮是快速「顺藤摸瓜」的好办法：把鼠标停在核心节点上，一圈邻居会立刻显现。

## 使用场景

- 俯瞰知识网络的**整体结构**
- 找出**核心笔记**（节点最大的那些）
- 发现**孤立笔记**（灰色、无连线），回头补链
- 理解知识体系的脉络与聚类
