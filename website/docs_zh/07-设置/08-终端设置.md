# 终端设置

终端设置控制内置终端的**配色、字体与字号**，让命令行窗口既清晰又贴合你的应用主题。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「终端」标签。终端本身的用法见 [[08-高级功能/05-终端]]。

## 配色方案

选择终端的配色方案，「自动」会跟随应用主题：

| 方案 | 说明 |
| --- | --- |
| **自动（跟随主题）** | 浅色外观用浅色方案、深色外观用深色方案 |
| Campbell | Windows Terminal 经典配色 |
| Campbell PowerShell | Windows Terminal PowerShell 配色 |
| One Half Dark | One Half 深色 |
| One Half Light | One Half 浅色 |
| Solarized Dark | Solarized 深色 |
| Solarized Light | Solarized 浅色 |
| Tango Dark | Tango 深色 |
| Tango Light | Tango 浅色 |
| Vintage | 复古终端配色 |
| Dracula | 吸血鬼风格深色 |
| Retro | 复古绿屏风格 |

## 字体

终端使用的等宽字体，可从预设中选择，也可以自定义：

- **预设**：自动、Consolas、Cascadia Code、JetBrains Mono、Fira Code、Source Code Pro、Menlo、Monaco、Courier New
- **自定义字体**：直接输入 CSS `font-family` 字符串，例如 `"JetBrains Mono", monospace`；回车或失焦后生效

## 字号

终端文字大小，可在设置中调整；也可以在终端内用 **`Ctrl` + 鼠标滚轮**快速缩放。
