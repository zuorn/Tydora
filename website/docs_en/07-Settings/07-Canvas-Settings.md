# Canvas Settings

Canvas settings control **where new canvas files are stored** and how the **canvas interacts**, so the infinite canvas can serve both quick jotting and precise layout.

> [!NOTE]
> Press `Ctrl+,` to open Settings and switch to the "Canvas" tab. For how to use the canvas itself, see [[08-Advanced-Features/03-Whiteboard-Canvas]].

## Default Location for New Canvases

Configure where `.canvas` files created via "New canvas" are stored:

| Option | Description |
| --- | --- |
| The vault root | All canvases go in the vault root directory |
| The folder of the current file | Stored nearby, alongside the related notes |
| A specified attachment folder | All go into a directory you specify (fill in the "Attachment folder path", relative to the vault root) |

> [!TIP]
> Canvases are often used as "indexes / boards", so the vault root is the most convenient place to find them; if a canvas always serves a particular group of notes, "the folder of the current file" is handier.

## Alignment and Snapping

| Setting | Description |
| --- | --- |
| Snap to grid | Align cards to the background grid when moving and resizing them |
| Grid size | The granularity of the grid |
| Snap to objects | Align cards to nearby objects when moving and resizing them (alignment guides appear) |

> [!TIP]
> Turn on "Snap to grid" when you need precise placement, and "Snap to objects" for freeform arrangement — the latter aligns a card's edges to other cards automatically.

## Performance and View

| Setting | Description |
| --- | --- |
| Zoom threshold for hiding card content | Below this zoom level, card content is hidden and only outlines are drawn. Lower values save more performance, but content disappears sooner |
| Enable minimap | Show a minimap for navigation in a corner of the canvas |
| Minimap position | Top-left / bottom-left / bottom-right |

## Zoom Range

| Setting | Description |
| --- | --- |
| Minimum zoom | The lower bound for zooming out |
| Maximum zoom | The upper bound for zooming in |
