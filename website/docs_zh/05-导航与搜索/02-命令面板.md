# 命令面板

命令面板让你用键盘搜索并执行 Tydora 中的几乎所有命令——从格式化文本到打开图谱、分屏、导出，无需在菜单里翻找。

> [!NOTE]
> 快捷键：`Ctrl+P`。

## 使用方法

1. 按 `Ctrl+P` 打开命令面板。
2. 输入命令关键词进行模糊搜索。
3. 用方向键选择，按 `Enter` 执行；或点击结果。
4. 按 `Esc` 关闭。

## 命令分组

命令按类别组织，输入关键词时会同时匹配**命令名与别名**：

| 分组 | 示例 |
| --- | --- |
| 文件 | 保存文件、打开文件、新窗口打开、知识库 |
| 编辑 | 撤销、重做 |
| 格式 | 加粗、斜体、删除线、行内代码、代码块、超链接、引用、水平分割线 |
| 列表 | 无序列表、有序列表、任务列表 |
| 标题 | 一级 \~ 六级标题、段落 |
| 插入 | 插入图像、插入脚注、插入目录、插入公式、表格 |
| 视图 | 切换侧栏、切换编辑模式、打字机模式、思维导图、知识图谱、新建终端、左右 / 上下分屏 |
| 模式 | 切换到即时渲染模式 / 切换到源码模式（当前模式会带 ✓ 标记） |
| 工具 | 发布为网站 |
| 导出 | 复制为 Markdown、复制公众号、导出为 PDF / HTML / Word / 图片 / 图文卡片 |
| 窗口 | 最小化窗口、最大化窗口、关闭窗口 |
| 设置 | 打开设置，以及直接跳转到通用 / 主题 / 快捷键 / 思维导图 / 关系图谱 / 图像 / 白板等设置页 |

## 别名与搜索技巧

命令都配置了中英文别名，输入任意一种都能命中：

- 「知识库」也可用 `仓库`、`仓库管理` 搜到
- 「导出为 Word」也可用 `word`、`docx`、`文档` 搜到
- 「导出为图文卡片」也可用 `小红书`、`xhs`、`卡片` 搜到
- 「打开知识图谱」也可用 `图谱`、`graph` 搜到

> [!TIP]
> 已经绑定快捷键的命令会在右侧显示对应键位，方便边用边记。

## 最近使用的命令

面板会记忆你**最近执行过的命令**并置顶，重复操作更快一步。

## 与快速打开的区别

- 命令面板（`Ctrl+P`）搜**命令**。
- 快速打开（`Ctrl+O`）搜**文件**。
