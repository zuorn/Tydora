# 标签

标签是 WikiLink 之外的第二种关联方式。链接表达「这两篇笔记有明确指向」，标签表达「这些笔记属于同一主题」——两者互补，共同构成知识网络的骨架。

> [!NOTE]
> 侧栏的「标签」页签提供**列表**与**标签图谱**两种视图，默认分配在右侧栏。

## 创建标签

### 正文内联标签

在正文中直接写 `#标签名`：

```markdown
今天读了 #读书 里的一章，记几个 #方法论 的要点。
```

输入 `#` 时会触发**标签自动补全**：列出仓库中已有的标签，用 `↑` / `↓` 选择、`Enter` 或 `Tab` 确认；若没有任何匹配，按 `Enter` 会直接创建这个新标签。

### Frontmatter 标签

也可以在文件头部的元数据中声明：

```yaml
---
tags: [读书, 方法论]
---
```

两种写法**效果完全一致**，都会被纳入标签索引。详见 [[02-编辑器/07-Frontmatter]]。

## 标签页签

### 列表视图

- 列出当前仓库的所有标签，**按使用次数排序**，高频标签排在前面
- 顶部有筛选框，输入关键词即可过滤标签
- 点击任意标签 → 自动切换到「搜索」页签，并在搜索框中填入 `#标签名`，全局列出携带该标签的文档

### 标签图谱

点击页签标题栏的切换按钮可切到**标签图谱**：

- 节点是标签，**同一篇文档中同时出现的标签彼此相连**（共现关系）
- 相连的标签说明它们经常一起出现，可据此发现主题聚类
- 悬停 / 点击节点同样可以发起全局筛选

> [!TIP]
> 标签图谱回答的是「哪些主题总是一起出现」，而 [[03-知识管理/04-知识图谱]] 回答的是「哪些笔记互相引用」。两个图谱对照着看，能同时看到**主题结构**与**引用结构**。

## 用标签筛选笔记

标签筛选能力贯穿几个入口：

| 入口 | 用法 |
| --- | --- |
| 侧栏「搜索」页签 | 搜索框支持 `#标签 关键字` 语法：先取携带该标签的文档集合，再按关键字过滤正文 |
| [[05-导航与搜索/01-快速打开]] | 输入框同样支持 `#标签 关键字` |
| 标签页签 / 标签图谱 | 点击标签自动填入搜索框 |

> 标签支持层级前缀匹配，例如用 `#技术` 可以命中 `#技术/前端` 这类带前缀的标签。

## 使用建议

- **用链接表达具体引用，用标签表达主题归属**：两者不要互相替代
- **控制标签数量**：标签太细会退化成链接，太粗则失去筛选价值
- **定期回看标签图谱**：孤立在角落的标签往往说明命名不一致，值得合并
