# 分屏与多窗格

Tydora 的编辑区支持**分屏**：把窗口切成多个窗格，每个窗格独立打开文件、独立切换编辑模式，甚至可以是终端。写长文时对照资料、边写边跑命令，都不用来回切窗口。

> [!NOTE]
> 窗格（pane）指同一窗口内的分割区域；窗口（window）指独立的操作系统窗口。两者可以组合使用。

## 分屏

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl+\` | 左右分屏 |
| `Ctrl+-` | 上下分屏 |
| ``Ctrl+` `` | 新建终端窗格（左右方向） |

也可以从这些入口分屏：

- 命令面板（`Ctrl+P`）→「左右分屏 / 上下分屏 / 新建终端」
- 编辑器顶部「更多」菜单 →「左右分屏 / 上下分屏 / 新建终端」
- [[05-导航与搜索/01-快速打开]] 的结果项 →「右侧分屏打开 / 下方分屏打开」

> [!NOTE]
> `Ctrl+-` 同时是表格的「删除行」快捷键。焦点在表格内时优先删除行，在表格外时执行分屏。可在 [[07-设置/03-快捷键设置]] 中调整。

## 窗格操作

| 操作 | 方式 |
| --- | --- |
| 切换焦点 | 点击目标窗格任意位置 |
| 调整大小 | 拖动窗格之间的**分隔线** |
| 关闭窗格 | 点击窗格右上角的关闭按钮；或命令面板 →「关闭窗格」 |
| 移动窗格 | 开启 [[02-编辑器/11-Vim模式]] 后，用 Leader 菜单的 `H` / `J` / `K` / `L` 把当前窗格移到最左 / 最下 / 最上 / 最右 |

> [!TIP]
> 分屏可以嵌套：在已经分屏的窗格中再次分屏，会形成更复杂的布局树。每个窗格都保留自己的编辑模式与滚动位置。

## 窗格类型

| 类型 | 说明 |
| --- | --- |
| 编辑器窗格 | 打开 Markdown 文件，可独立切换 IR / SV 模式 |
| 白板窗格 | 在主区域显示 `.canvas` 白板 |
| 预览窗格 | 显示图片 / 视频 / 音频 / PDF |
| 终端窗格 | 真实的 shell 会话，详见 [[08-高级功能/05-终端]] |

## Vim 窗格导航

开启 Vim 模式后，normal 模式下可用 tmux 风格的键位在窗格间跳转：

| 快捷键 | 效果 |
| --- | --- |
| `Ctrl+h` / `Ctrl+j` / `Ctrl+k` / `Ctrl+l` | 焦点切换到左 / 下 / 上 / 右窗格 |

## 独立窗口

需要真正并排看两份内容时，可以把文件放到独立窗口：

- 文件树右键 →「在新窗口中打开」
- [[05-导航与搜索/01-快速打开]] →「新窗口打开」
- 知识图谱 / 思维导图 / 白板都可单独开窗，便于放到副屏

> 窗口位置与大小会被记住，下次启动自动恢复。
