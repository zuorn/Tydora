# Terminal Settings

Terminal settings control the built-in terminal's **color scheme, font, and font size**, keeping the command line legible and in harmony with your app theme.

> [!NOTE]
> Press `Ctrl+,` to open Settings and switch to the "Terminal" tab. For how to use the terminal itself, see [[08-Advanced-Features/05-Terminal]].

## Color Scheme

Choose the terminal's color scheme; "Auto" follows the app theme:

| Scheme | Description |
| --- | --- |
| **Auto (follow theme)** | A light scheme for a light appearance, a dark scheme for a dark appearance |
| Campbell | The classic Windows Terminal palette |
| Campbell PowerShell | The Windows Terminal PowerShell palette |
| One Half Dark | One Half dark |
| One Half Light | One Half light |
| Solarized Dark | Solarized dark |
| Solarized Light | Solarized light |
| Tango Dark | Tango dark |
| Tango Light | Tango light |
| Vintage | A vintage terminal palette |
| Dracula | The vampire-inspired dark palette |
| Retro | A retro green-screen look |

## Font

The monospace font used by the terminal. Choose from presets or define your own:

- **Presets**: Auto, Consolas, Cascadia Code, JetBrains Mono, Fira Code, Source Code Pro, Menlo, Monaco, Courier New
- **Custom font**: type a CSS `font-family` string directly, e.g. `"JetBrains Mono", monospace`; it applies on Enter or blur

## Font Size

The terminal's text size is adjustable in Settings; you can also zoom quickly inside the terminal with **`Ctrl` + the mouse wheel**.
