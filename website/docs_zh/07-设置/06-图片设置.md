# 图片设置

图片设置决定粘贴或拖入图片时的**存储位置与命名规则**，让你在「随仓库管理」与「集中存放」之间自由选择。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「图像」标签。

## 按文档隔离存放

无论选择哪种存储位置，图片都会放进 `assets/` 下**以文档名命名的子目录**，不同文档的图片互不混放：

```
仓库根/assets/我的笔记/截图-20240101120000.png
```

- 文档重命名后，对应的图片子目录同步改名，文档内的引用一并更新
- 新建但尚未保存的文档，图片先存放在 `assets/untitled/`，首次保存后自动改名为文档名子目录
- 删除文档不会自动删除其图片子目录，需要时可手动清理

## 存储位置

### 仓库 assets 目录（默认）

图片保存在**当前仓库根目录下的 `assets/文档名/`** 中。

- 优点：图片随仓库一起管理、移动、备份，链接不易失效
- 缺点：仓库体积会随图片增多而变大

配套选项：

| 选项 | 说明 |
| --- | --- |
| 自动创建 assets 目录 | 目录不存在时自动创建（默认开启） |

### 同级目录（与文档同目录）

`assets/` 建在**文档所在目录**下，即 `文档目录/assets/文档名/`。

- 优点：图片与文档紧邻，单独拷走一个文件夹即可带走全部素材，适合按主题分层的知识库
- 缺点：同一目录中文档较多时子目录数量随之增加

文档尚未保存时没有「同级目录」可用，此时退回仓库 `assets/`；既未保存也没有打开仓库时，会弹出目录选择器让你指定存放位置。

### 固定本地目录

图片保存在**固定的本地目录**中，与具体仓库解耦，其下仍按文档名隔离子目录（`固定目录/文档名/`）。

- 优点：多个仓库可共用同一图库
- 缺点：路径依赖本地环境，换机器或移动目录后可能失效

选择该模式后，需要在「存储路径」中指定目录（可通过「选择目录...」按钮挑选）。

### 图床上传（后续支持）

图床模式目前**尚未实现**，设置中会显示「图床上传（后续支持）」并给出提示。当前请使用前几种本地存储方式。

## 引用路径格式

写入文档的图片引用有两种形式，默认为**相对路径**：

| 格式 | 示例 | 说明 |
| --- | --- | --- |
| 相对路径（默认） | `./assets/我的笔记/截图.png` | 以文档所在目录为基准；文档在子目录中时会是 `../assets/...` |
| 绝对路径 | `D:/notes/仓库/assets/我的笔记/截图.png` | 使用正斜杠的文件系统路径，跨目录引用直观但换机器易失效 |

文档未保存、或图片与文档不在同一磁盘分区时，相对路径无法表达，引用会自动写成绝对路径。

## 文件命名格式

设置粘贴图片时自动生成的文件名：

| 格式 | 示例 | 说明 |
| --- | --- | --- |
| 原始名称 | `截图.png` | 保留图片本来的文件名 |
| 时间戳 | `20240101120000.png` | 按时间唯一命名 |
| 原始名称 + 时间戳（默认） | `截图-20240101120000.png` | 既保留语义又避免重名 |

> [!TIP]
> 多人协作或需溯源时用「原始名称」更直观；个人笔记推荐默认的「原始名称 + 时间戳」，可避免同名图片互相覆盖。

## 支持的格式

粘贴与拖拽识别以下图片格式：

PNG、JPG / JPEG、GIF、WebP、BMP、SVG、AVIF、ICO
