# 内置主题

Tydora 提供 **10 款**精心设计的内置主题，覆盖清新、沉稳、活力、未来感等多种风格。你可以在设置中一键切换，也可以自建或导入主题（见 [[06-主题与外观/02-自定义主题]]）。

> [!NOTE]
> 默认外观模式为**跟随系统**：系统为浅色时使用「云白」，系统为深色时使用「Mint Dark」。代码块的配色独立于应用主题，详见 [[06-主题与外观/03-代码高亮主题]]。

## 切换主题

1. 打开设置（`Ctrl+,`）。
2. 切换到「主题」标签。
3. 在「内置主题」区点击主题卡片，立即生效。

> [!TIP]
> 主题卡片上会显示该主题的代表色块，方便快速对比。悬停卡片还可以「复制并编辑」，把内置主题 fork 成自定义主题后逐项改色。

## 外观模式

Tydora 支持三种外观模式：

| 模式 | 说明 |
| --- | --- |
| **跟随系统**（默认） | 自动匹配操作系统的浅色 / 深色设置 |
| **浅色** | 强制浅色渲染 |
| **深色** | 强制深色渲染 |

> 外观模式在「主题」标签顶部设置，也可在 [[07-设置/01-通用设置]] 的「外观」分组中调整。

### 浅色偏好 / 深色偏好

Tydora 为浅色与深色**分别保存一套偏好**，每套包含：

- **应用主题**（界面配色）
- **代码主题**（代码高亮配色）

也就是说，你可以让浅色模式用「云白 + GitHub Light」，深色模式用「Mint Dark + Dracula」，切换外观时自动各就各位。设置页顶部会显示当前的组合，例如「当前：跟随系统 · 云白 + GitHub Light」。

> [!TIP]
> 「跟随系统」模式下如果系统在一天中切换了深浅色，Tydora 会同步切换到你为对应外观设定的那套偏好，而不是简单地把界面反色。
