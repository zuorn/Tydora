# 关于 Tydora

Tydora 是一款基于 Tauri v2 + React 19 构建的现代化桌面 Markdown 编辑器，支持 WYSIWYG 与源码双模式编辑、WikiLink 双向链接、知识图谱、思维导图、白板画布等功能。其名取自 *Type/Typography* 与古希腊语 *δῶρον（礼物）*，意为「指尖上的礼物」。

> [!NOTE]
> Tydora 是开源软件，采用 Apache License 2.0 许可证。欢迎在 GitHub 上提 Issue、参与讨论或贡献代码。

## 检查更新

Tydora 支持自动更新：启动时会在后台自动检查是否有新版本，若有则提示你下载安装。

手动检查步骤：

1. 打开设置（按 `Ctrl+,`）。
2. 切换到「关于」标签。
3. 点击「检查更新」。

> [!TIP]
> 自动更新依赖 GitHub Releases 上的签名文件（`.sig` 与 `latest.json`）。相关配置详见 [[09-blog/自动更新配置]]（面向贡献者）。

## 功能特性一览

- **双模式编辑**：即时渲染（IR / WYSIWYG）+ 源码模式（SV），`Ctrl+/` 切换
- **多仓库管理**：基于文件夹的仓库，文件树拖拽组织
- **WikiLink 双向链接**：`[[笔记名]]` 语法，自动补全 + 反向链接面板
- **知识图谱**：基于 D3.js 力导向图，可视化笔记关系
- **思维导图**：从 Markdown 标题层级自动生成，Markmap 驱动
- **白板画布**：React Flow 无限画布，支持文本 / 笔记 / 图片 / 媒体 / URL / 分组节点
- **Callout 提示块**：15 种 GitHub 风格类型
- **Mermaid 图表**：流程图、时序图、甘特图等实时渲染
- **数学公式**：KaTeX / MathJax 双引擎
- **Frontmatter 属性面板**：YAML 元数据管理
- **一键发布**：Vault 发布为静态网站，内置预览服务器
- **主题系统**：9 款内置主题 + 自定义/Typora 主题导入
- **代码高亮**：11 款高亮配色，支持 36 种语言
- **可定制快捷键**：40+ 快捷键，全部可在设置中重绑定
- **多媒体预览**：图片、视频、音频、PDF
