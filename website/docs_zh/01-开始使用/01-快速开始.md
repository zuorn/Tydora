# 快速开始

Tydora 是一款基于 Tauri v2 + React 19 构建的现代化桌面 Markdown 编辑器，支持 WYSIWYG 即时渲染、源码双模式编辑、WikiLink 双向链接、标签与书签、知识图谱、思维导图、白板画布、内置终端与多格式导出。本页带你从安装到写下第一篇笔记，约 5 分钟上手。

> [!NOTE]如果你已经在用 Obsidian 或 Typora，会发现 Tydora 的很多交互十分熟悉：仓库（Vault）概念、双链语法、即时渲染编辑，都与它们一脉相承。

## 一、安装

打开 [GitHub Releases](https://github.com/zuorn/Tydora/releases) 页面。

1. 根据你的系统下载对应的安装包：
   - **Windows**：`Tydora_x.x.x_x64-setup.exe`（也可通过 Microsoft Store 安装）
   - **macOS**：`Tydora_aarch64.app.tar.gz`（Apple 芯片）或 `Tydora_x64.app.tar.gz`（Intel）
   - **Linux**：`Tydora_amd64.AppImage`
2. 运行安装程序，按提示完成安装。
3. 启动 Tydora。

> [!TIP]首次启动后，Tydora 会在后台检查是否有可用更新（详见 [[01-开始使用/02-关于]] 的「检查更新」）。你也可以随时在设置的「关于」标签手动检查。

## 二、打开仓库

Tydora 使用「仓库（Vault）」概念来管理你的笔记文件。**每个仓库对应本地的一个文件夹**，仓库里的所有 Markdown 文件、白板文件都会被纳入文件树、链接索引、标签索引与知识图谱。

1. 点击左侧边栏底部的**仓库切换器**（通常显示当前仓库名）。
2. 选择「管理仓库」或「添加仓库」。
3. 在系统文件选择器中，挑选一个文件夹作为你的笔记仓库（也可以新建一个空文件夹）。
4. 确认后，左侧边栏会立即显示该文件夹的**文件树**。

> [!ABSTRACT]仓库仅记录文件夹路径，不会移动或复制你的文件。你可以随时添加多个仓库，按项目或主题分别管理。详见 [[04-文件管理/01-仓库]]。

## 三、创建你的第一篇笔记

1. 在左侧**文件树**中，右键点击目标文件夹（或根目录）。
2. 选择「新建文件」。
3. 输入文件名，例如 `我的第一篇笔记.md`（`.md` 后缀可省略，Tydora 会自动补上）。
4. 按 `Enter` 确认，编辑器即打开该文件。
5. 开始用 Markdown 写作吧！

> [!TIP]在文件树空白处右键也可「新建文件夹」或「新建白板」，先把笔记分类存放，知识才不会变成一团乱麻。

## 四、基本编辑

Tydora 提供两种编辑模式，满足不同场景：

- **即时渲染（IR / WYSIWYG）**：直接在编辑器里看到最终效果，所见即所得，适合日常写作。
- **源码模式（SV）**：显示纯 Markdown 文本，由 CodeMirror 6 提供语法高亮，适合精细调整格式。

> 按 `Ctrl+/` 可在两种模式间随时切换。详见 [[02-编辑器/01-编辑模式]]。

如果你习惯 Vim 键位，还可以在设置的「Vim 模式」标签中开启 Vim 支持（默认关闭）。详见 [[02-编辑器/11-Vim模式]]。

## 五、保存文件

- 手动保存：按 `Ctrl+S`。
- 自动保存：**默认开启**，文件会在你停止输入约 1 秒后自动写入磁盘；可在 [[07-设置/01-通用设置]] 的「行为」分组中关闭。

> [!WARNING]删除文件不可撤销（不会进入系统回收站），请谨慎操作。重要笔记建议先备份，或纳入版本管理（如 Git）。

| `Ctrl+Tab` | 切换左侧边栏显示/隐藏 |
| `Ctrl+/` | 切换编辑模式（IR ↔ SV） |

> 完整列表见 [[07-设置/04-快捷键速查]]。

## 七、下一步

写好第一篇笔记后，推荐继续探索：

- 用 `[[另一篇笔记]]` 建立双向链接，让笔记彼此相连 → [[03-知识管理/01-Wiki链接]]
- 用 `#标签` 给笔记打标签，在侧栏「标签」页签里查看标签图谱 → [[03-知识管理/06-标签]]
- 把常用文件加入「书签」，一触即达 → [[03-知识管理/07-书签]]
- 按 `Ctrl+G` 看看你的知识图谱长什么样 → [[03-知识管理/04-知识图谱]]
- 想分享出去？导出为 PDF / Word，或一键发布成网站 → [[08-高级功能/04-导出与复制]]、[[08-高级功能/01-发布网站]]
