# 仓库（Vault）

Tydora 使用「仓库（Vault）」概念来管理笔记文件。**每个仓库就是一个本地文件夹**，仓库内的所有 Markdown 文件、白板文件、子文件夹与图片都会被纳入文件树、链接索引、标签索引与知识图谱。

> [!NOTE]
> 仓库只记录文件夹的**路径**，不会移动、复制或改动你的任何文件。你可以放心地把已有的 Markdown 文件夹直接添加为仓库。

## 打开与管理仓库

侧栏底部有一个**仓库切换器**，显示当前仓库名；旁边可进入**管理仓库**窗口。管理仓库窗口提供以下能力：

| 操作 | 说明 |
| --- | --- |
| 新建仓库 | 在指定位置创建一个新文件夹作为仓库 |
| 打开本地文件夹 | 把已有的文件夹添加为仓库 |
| 切换仓库 | 点击列表中的仓库，在新窗口中打开它 |
| 重命名 | 修改仓库在 Tydora 中的显示名 |
| 移动 | 把仓库文件夹整体移动到新位置 |
| 在资源管理器中显示 | 在系统文件管理器中定位该文件夹 |
| 移除 | 解除 Tydora 对该文件夹的引用（**不删除文件**） |

> [!WARNING]
> 移除仓库**只是解除 Tydora 对它的引用**，不会删除磁盘上的文件夹与文件。确认对话框会明确提示这一点。若想彻底删除，请在文件管理器中操作。

## 切换仓库

1. 点击仓库切换器，或进入管理仓库窗口。
2. 在列表中选择目标仓库。
3. 仓库会在新窗口中打开，文件树、链接索引与图谱随之切换。

> [!TIP]
> 多仓库适合按项目、按主题或按公私分开放置笔记。例如：一个仓库放工作笔记，一个仓库放个人知识库。当前激活的仓库会被记住，下次启动自动恢复。

## 多仓库隔离

- 每个仓库独立维护文件树、链接索引、标签索引与书签
- 切换仓库时，若本地缓存的索引属于另一个仓库，会自动重建，不会串数据
- 仓库之间不会互相解析 `[[链接]]`

## 最近打开的文件

Tydora 会记录最近访问过的文件，在 [[05-导航与搜索/01-快速打开]] 面板打开时会优先展示，方便快速回到上次编辑的位置。

## 文件系统监控

Tydora 会监控仓库文件夹的外部变动：当你在文件管理器里新增、重命名或删除文件时，文件树与索引会**自动更新**，无需手动刷新。

> [!NOTE]
> 外部修改触发的索引更新是增量的，仅处理变化的部分，不会卡顿编辑器。详见 [[03-知识管理/05-链接索引]]。
