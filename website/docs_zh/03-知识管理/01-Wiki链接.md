# Wiki 链接

Wiki 链接是 Tydora 知识管理的核心：用 `[[笔记名]]` 就能在笔记之间建立**双向链接**，把零散的笔记织成网络。语法与 Obsidian 一致。

> [!NOTE]
> 输入 `[[` 即触发自动补全，输入关键词即可筛选目标笔记。链接解析依赖 [[03-知识管理/05-链接索引]]。

## 基本语法

### 链接到笔记

```markdown
[[笔记名]]
```

渲染为可点击的链接，点击后跳转到对应笔记。

### 带别名的链接

```markdown
[[笔记名|显示文本]]
```

显示「显示文本」，但指向「笔记名」。适合在句中自然引用。

### 链接到标题

```markdown
[[笔记名#标题]]
```

直接跳转到目标笔记中的指定标题位置。

### 带路径的链接

当仓库中存在同名笔记时，可以用路径消除歧义：

```markdown
[[文件夹/笔记名]]
[[笔记名.md]]
[[我的白板.canvas]]
```

> [!TIP]
> 不带路径时，Tydora 会先做**大小写不敏感的按文件名匹配**；若多个文件同名，取路径最短的那个。要精确指向，请写上相对路径。

## 使用方法

1. 在编辑器中输入 `[[`。
2. 继续输入笔记名（支持模糊匹配）。
3. 从自动补全列表中选择目标。
4. 按 `Enter` 确认，链接插入完成。

> [!TIP]
> 候选列表会显示匹配的文件路径，重名笔记也能准确区分。若**没有任何匹配结果**，按 `Enter` 会以你输入的名字**创建一篇新笔记**并打开它。

## 自动补全

输入 `[[` 后，Tydora 会弹出匹配笔记列表：

- 支持**模糊搜索**：输入部分关键词即可过滤
- 实时更新：边输入边筛选
- 键盘操作：`↑` / `↓`（或 `Ctrl+K` / `Ctrl+J`）选择，`Enter` 确认，`Esc` 关闭

> 在即时渲染模式下，右键菜单的「插入 → WikiLink」也可以直接插入 `[[` 并唤出补全列表。

## 链接到不存在的笔记

如果链接指向的笔记尚不存在，**点击该链接会自动创建**一篇同名笔记（内容为 `# 笔记名`）并打开它。这让「先链接、后补全」的写作流非常顺滑。

## 悬停预览

把鼠标移到 WikiLink 上，会弹出**预览卡片**：

- 普通笔记：显示渲染后的正文内容
- `.canvas` 白板文件：显示缩略图
- 目标不存在时提示未找到

> [!TIP]
> 预览卡片支持继续悬停其中的链接，逐层深入查看，不必真的跳转过去。

## 重命名自动修复

在文件树中**重命名或移动**笔记时，Tydora 会扫描全仓库，把所有指向它的 `[[旧名]]` 引用改写为新名称，并刷新链接索引。你不需要手工修复断链。

## 嵌入内容

在 `[[` 前加 `!` 可插入图片（Obsidian 嵌入语法）：

```markdown
![[图片.png]]
![[图片.png|400]]
```

> 详见 [[03-知识管理/02-嵌入内容]]。

## 反向链接与图谱

所有 `[[笔记名]]` 关系都会汇总到链接索引，并可在图谱中可视化。查看「谁引用了我」的方式见 [[03-知识管理/03-反向链接]]，网状视角见 [[03-知识管理/04-知识图谱]]。
